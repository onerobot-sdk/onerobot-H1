升降机构 (Lift) ​

控制接口 ​

话题消息类型说明
/lift/cmd_velgeometry_msgs/msg/Twist升降速度控制，使用 linear.z（上升为正，下降为负）
/lift/joint_states/updatesensor_msgs/msg/JointState升降绝对高度控制，name 固定为 ["lift_joint"]，position 为目标高度（米）；可选 velocity 指定运行速度（见下方说明），缺省按默认速度运行

状态反馈 ​

话题消息类型说明
/lift/odomnav_msgs/msg/Odometry升降里程计，pose.pose.position.z 为当前离地高度（约 0.4m ~ 1.3m）
/lift/joint_statessensor_msgs/msg/JointState升降关节状态，position[0] 为当前高度值
/lift/alarmstd_msgs/msg/String（JSON）升降电机报警状态，含当前报警码/中文描述及历史报警；状态变化时发布，transient_local 锁存

关于绝对高度控制的速度（velocity 字段）

下发 /lift/joint_states/update 时，可在与 lift_joint 对应的 velocity 元素里指定运行速度：

  • 不带 velocity（或值 ≤ 0）： 使用默认速度 400 RPM。
  • 带有效 velocity： 使用该值作为电机转速（单位 RPM，会被限制在 [30, 800]）。

速度单位为电机转速 RPM（转/分），对应升降线速度约为 RPM × 0.167 mm/s，即 30~800 RPM ≈ 5~133.6 mm/s。

升降报警 (/lift/alarm) ​

升降电机的报警状态，可用于监控过流、过压、编码器错误等故障。

  • 消息类型： std_msgs/msg/String（JSON 格式）
  • QoS： transient_local（锁存，最新状态保留给后加入的订阅者）
  • 发布时机： 报警状态变化时发布；节点启动后首个周期会发一次当前状态作为基线。

消息格式：

json
{
  "current_code": 0,
  "current_text": "正常",
  "history1_code": 0,
  "history2_code": 0,
  "history3_code": 0,
  "text": "升降电机当前报警: 正常 历史报警1: 正常 历史报警2: 正常 历史报警3: 正常",
  "stamp": {"sec": 1749686400, "nanosec": 123456789}
}

字段类型说明
current_codeint当前报警码（见下表），0 = 正常
current_textstring当前报警码的中文描述
history1_code ~ history3_codeint最近 3 次历史报警码

码含义码含义

头部电机 (Head) ​

支持 Pitch（俯仰）和 Yaw（左右）控制。

控制接口 ​

话题消息类型说明
/head/cmd_velgeometry_msgs/msg/Twist头部速度控制，使用 angular.y（Pitch，抬头为负、低头为正）和 angular.z（Yaw，左转为负、右转为正）
/head/joint_states/updatesensor_msgs/msg/JointState头部绝对角度控制，name 为 ["head_pitch_joint"]（俯仰）和 ["head_yaw_joint"]（左右），position 为目标角度（弧度，抬头为正、左转为正，方向与上面的速度控制相反）

⚠️ 速度控制与绝对角度控制的方向符号相反（底层伺服速度寄存器与位置寄存器的正方向定义不同）：

  • 速度（/head/cmd_vel）： angular.y 负=抬头、正=低头；angular.z 负=左转、正=右转。
  • 绝对角度（/head/joint_states/update）： position 正=抬头/左转、负=低头/右转。

状态反馈 ​

话题消息类型说明
/head/odomnav_msgs/msg/Odometry头部里程计，包含当前姿态角速度信息
/head/stallstd_msgs/msg/String（JSON）头部 Pitch/Yaw 电机堵转状态；状态变化时发布，transient_local 锁存

头部堵转 (/head/stall) ​

头部 Pitch（俯仰）/Yaw（左右）电机的堵转状态，可用于判断头部是否被卡住或撞到机械限位。

  • 消息类型： std_msgs/msg/String（JSON 格式）
  • QoS： transient_local（锁存，最新状态保留给后加入的订阅者）
  • 发布时机： 堵转状态变化时发布；节点启动时发一次基线（默认未堵转），头部校准撞限位期间也会发布。

消息格式：

json
{
  "pitch_stall": false,
  "yaw_stall": false,
  "stamp": {"sec": 1749686400, "nanosec": 123456789}
}

字段类型说明
pitch_stallboolPitch（俯仰）电机堵转，true = 已堵转
yaw_stallboolYaw（左右）电机堵转，true = 已堵转

限位开关 (Limit Switches) ​

升降与头部共 6 个外部限位开关（机械行程端点）的状态通过同一个话题发布，可用于判断升降/头部是否已到达行程极限。

  • 话题： /body/limit_switch
  • 消息类型： std_msgs/msg/String（JSON 格式）
  • QoS： transient_local（锁存，最新状态会保留给后加入的订阅者）
  • 发布时机： 任一限位状态发生变化（触发/释放）时发布；节点启动时另主动发一次基线。

消息格式：

json
{
  "lift_top": false,
  "lift_bottom": false,
  "head_pitch_up": false,
  "head_pitch_down": false,
  "head_yaw_left": false,
  "head_yaw_right": false,
  "stamp": {"sec": 1749686400, "nanosec": 123456789}
}

字段说明：

字段类型说明
lift_topbool升降顶部限位，true = 已到顶（撞顶）
lift_bottombool升降底部限位，true = 已到底（撞底）
head_pitch_upbool头部俯仰上限位，true = 抬头到顶
head_pitch_downbool头部俯仰下限位，true = 低头到底
head_yaw_leftbool头部左右左限位，true = 左转到位
head_yaw_rightbool头部左右右限位，true = 右转到位
stampobject该状态最近一次变化的时间，sec/nanosec（ROS 时钟）

某方向限位触发后，该方向的运动会被立即停止；反向运动不受影响。

机械臂 (Arms) ​

支持 MoveJ、MoveP、MoveL 指令。控制命令使用 std_msgs/msg/String 承载 JSON。

控制接口 ​

话题消息类型说明
/left_arm/movejstd_msgs/msg/String（JSON）左臂关节空间运动
/right_arm/movejstd_msgs/msg/String（JSON）右臂关节空间运动
/left_arm/movepstd_msgs/msg/String（JSON）左臂末端位姿运动（点到点）
/right_arm/movepstd_msgs/msg/String（JSON）右臂末端位姿运动（点到点）
/left_arm/movelstd_msgs/msg/String（JSON）左臂末端直线运动
/right_arm/movelstd_msgs/msg/String（JSON）右臂末端直线运动
/left_arm/stopstd_msgs/msg/Empty中断左臂当前运动
/right_arm/stopstd_msgs/msg/Empty中断右臂当前运动
/action/stopstd_msgs/msg/Empty同时中断左右臂当前运动

字段类型说明
pose.positionobject末端目标位置，x/y/z，单位 m
pose.orientationobject末端目标方向，四元数 x/y/z/w
speed_scalenumber可选，速度倍率；范围 [0.01, 5.0]，缺省 1.0

执行反馈 ​

  • 话题： /arm_diagnostics (diagnostic_msgs/msg/DiagnosticStatus)
字段说明
name执行的臂："left_arm" 或 "right_arm"
level0 = OK（完成），2 = ERROR（失败）
message结果描述，如 "motion completed" 或错误原因
values扩展键值对，如 motion_type、目标/实际位置、误差、耗时、电机错误等

遗弃接口（Deprecated） ​

⚠️ 以下接口已遗弃，保留用于已有项目兼容。

  • MoveJ 控制输入： /movej_left_angle, /movej_right_angle (std_msgs/msg/Float64MultiArray)
    • 数据格式：[j1, j2, j3, j4, j5, j6, j7]
    • 可选速度倍率：[j1, j2, j3, j4, j5, j6, j7, speed_scale]
    • 可选逐关节速度：[j1..j7, v1..v7] 或 [j1..j7, v1..v7, speed_scale]
  • MoveP 控制输入： /movep_left_pose, /movep_right_pose (std_msgs/msg/Float64MultiArray)
    • 数据格式：[x, y, z, qx, qy, qz, qw, quick_movej_duration_s, speed_scale]
    • 第 8、9 位可省略
  • MoveL 控制输入： /movel_left_pose, /movel_right_pose (std_msgs/msg/Float64MultiArray)
    • 数据格式：[x, y, z, qx, qy, qz, qw, speed_mps, speed_scale]
    • 第 8、9 位可省略；speed_mps 缺省 0.05
  • 执行反馈： /arm_move_info (std_msgs/msg/Int32)
    • 10: 左臂执行失败，11: 左臂执行完成，20: 右臂执行失败，21: 右臂执行完成

灯光控制 ​

机器人有 4 个灯板，通过 /light_board/control 话题控制。

  • 话题： /light_board/control
  • 消息类型： std_msgs/msg/String（JSON 格式）

消息格式：

json
{
  "boards": [
    {"color": "#FF0000", "brightness": 100, "blink_hz": 0},
    {"color": "#FF0000", "brightness": 100, "blink_hz": 0},
    {"color": "#FF0000", "brightness": 100, "blink_hz": 0},
    {"color": "#FF0000", "brightness": 100, "blink_hz": 0}
  ]
}

字段说明：

字段类型说明
colorstringCSS 十六进制颜色，如 "#FF0000"（红）、"#00FF00"（绿）、"#FFFFFF"（白）
brightnessint亮度，范围 0–100，0 表示关闭
blink_hzfloat闪烁频率（Hz），0 表示常亮

boards 数组长度固定为 4，索引 0–3 对应灯板 1–4。不需要控制的灯板设为 null 跳过。

示例命令 ​

灯板控制 ​

bash
# 四个灯板红色 100% 常亮
ros2 topic pub --once /light_board/control std_msgs/msg/String \
  '{data: "{\"boards\": [{\"color\":\"#FF0000\",\"brightness\":100,\"blink_hz\":0},{\"color\":\"#FF0000\",\"brightness\":100,\"blink_hz\":0},{\"color\":\"#FF0000\",\"brightness\":100,\"blink_hz\":0},{\"color\":\"#FF0000\",\"brightness\":100,\"blink_hz\":0}]}"}'

# 四个灯板红色 50% 亮度，10Hz 闪烁
ros2 topic pub --once /light_board/control std_msgs/msg/String \
  '{data: "{\"boards\": [{\"color\":\"#FF0000\",\"brightness\":50,\"blink_hz\":10},{\"color\":\"#FF0000\",\"brightness\":50,\"blink_hz\":10},{\"color\":\"#FF0000\",\"brightness\":50,\"blink_hz\":10},{\"color\":\"#FF0000\",\"brightness\":50,\"blink_hz\":10}]}"}'

# 关闭所有灯
ros2 topic pub --once /light_board/control std_msgs/msg/String \
  '{data: "{\"boards\": [{\"color\":\"#000000\",\"brightness\":0,\"blink_hz\":0},{\"color\":\"#000000\",\"brightness\":0,\"blink_hz\":0},{\"color\":\"#000000\",\"brightness\":0,\"blink_hz\":0},{\"color\":\"#000000\",\"brightness\":0,\"blink_hz\":0}]}"}'

# 仅灯板 1 绿色 100% 常亮，其余跳过
ros2 topic pub --once /light_board/control std_msgs/msg/String \
  '{data: "{\"boards\": [{\"color\":\"#00FF00\",\"brightness\":100,\"blink_hz\":0},null,null,null]}"}'

# 灯板 1 白色 100% 常亮
ros2 topic pub --once /light_board/control std_msgs/msg/String \
  '{data: "{\"boards\": [{\"color\":\"#FFFFFF\",\"brightness\":100,\"blink_hz\":0},null,null,null]}"}'

升降控制 ​

bash
# 升降校准
ros2 topic pub /body_general_control std_msgs/msg/Int32 'data: 2' -1

# 清除升降堵转报警
ros2 topic pub /body_general_control std_msgs/msg/Int32 'data: 1' -1

# 速度控制 — 上升（linear.z = 1.0）
ros2 topic pub --once /lift/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 1.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"

# 速度控制 — 下降（linear.z = -1.0）
ros2 topic pub --once /lift/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: -1.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"

# 速度控制 — 停止
ros2 topic pub --once /lift/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"

# 持续上升（10Hz发布，linear.z = 0.5）
ros2 topic pub -r 10 /lift/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.5}, angular: {x: 0.0, y: 0.0, z: 0.0}}"

# 控制至绝对高度 1.10m（默认速度）
ros2 topic pub --once /lift/joint_states/update sensor_msgs/msg/JointState '{name: ["lift_joint"], position: [1.10]}'

# 控制至绝对高度 1.10m，并指定速度 300 RPM（velocity 与 lift_joint 对应）
ros2 topic pub --once /lift/joint_states/update sensor_msgs/msg/JointState '{name: ["lift_joint"], position: [1.10], velocity: [300.0]}'

# 查看当前高度（odom）
ros2 topic echo /lift/odom

# 查看当前关节状态
ros2 topic echo /lift/joint_states

# 查看升降报警状态（QoS 需匹配 transient_local 才能收到锁存的最新值）
ros2 topic echo /lift/alarm --qos-durability transient_local

头部控制 ​

bash
# 头部校准
ros2 topic pub /body_general_control std_msgs/msg/Int32 'data: 3' -1
