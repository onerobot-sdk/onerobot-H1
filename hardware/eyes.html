眼睛控制 ​

控制眼睛的表情与亮度，支持自定义资源包管理。

接口总览 ​

话题消息类型方向说明
/eyes/expressionstd_msgs/msg/String发布设置表情 ID，支持左/右/双眼
/eyes/brightnessstd_msgs/msg/Int32发布亮度控制，1-100
/eyes/resourcestd_msgs/msg/String发布资源包管理（上传/激活/查询/删除）
/eyes/resource_statusstd_msgs/msg/String订阅资源包操作反馈
/eyes/statestd_msgs/msg/String订阅当前眼睛状态（表情 ID、亮度，10 Hz）

表情控制（/eyes/expression） ​

向 /eyes/expression 发布 JSON，设置左眼、右眼或双眼的表情 ID。

消息类型： std_msgs/msg/String（JSON 格式）

json
{
  "target": "both",
  "expression_id": 2
}

字段类型必填说明
targetstring否"both"（默认）/ "left" / "right"
expression_idint是当前激活资源包中的表情 ID（0-65535）

系统内置表情 ID（只读，始终可用）：

expression_id表情
0正常（Normal）
1开心（Happy）

亮度控制（/eyes/brightness） ​

消息类型： std_msgs/msg/Int32

范围 1-100，1 最暗，100 最亮。

资源包管理（/eyes/resource） ​

资源包是一个 zip 压缩文件，包含若干 GIF 素材和一个 manifest.json 描述文件，定义表情 ID 与素材文件的映射关系。

压缩包结构 ​

my_pack.zip
├── manifest.json
├── normal_R.gif
├── normal_L.gif
├── sad_R.gif
└── sad_L.gif

字段说明
package_id资源包唯一标识，与 zip 文件名建议保持一致
resources[].expression_id表情 ID，0-65535
resources[].name表情名称，仅用于描述
resources[].file_right右眼 GIF 文件名（zip 包内路径）
resources[].file_left左眼 GIF 文件名（zip 包内路径）

系统内置资源包 "builtin" 只读，包含 ID 0（正常）和 ID 1（开心），不可覆盖或删除。

当前眼睛状态（/eyes/state） ​

眼睛模块以 10 Hz 向 /eyes/state 持续发布当前状态。

消息类型： std_msgs/msg/String（JSON 格式）

json
{
  "stamp": {
    "sec": 1745000000,
    "nanosec": 123456789
  },
  "active_package": "my_pack",
  "left_expression_id": 2,
  "right_expression_id": 2,
  "brightness": 80
}

right_expression_idint右眼当前显示的表情 ID

数据流 ​

准备 zip（GIF 素材 + manifest.json）
          ↓ 拷贝到机器人本地
/eyes/resource  {"cmd": "upload",   "zip_path": "/home/user/eye_packs/my_pack.zip"}
          ↓ 解包 + 写入眼睛板
/eyes/resource  {"cmd": "activate", "package_id": "my_pack"}
          ↓
/eyes/expression  {"target": "both", "expression_id": 2}
          ↓
/eyes/state  ← 持续发布当前状态

示例命令 ​

bash
# 上传资源包
ros2 topic pub --once /eyes/resource std_msgs/msg/String \
  "{data: '{\"cmd\": \"upload\", \"zip_path\": \"/home/user/eye_packs/my_pack.zip\"}'}"

# 激活资源包
ros2 topic pub --once /eyes/resource std_msgs/msg/String \
  "{data: '{\"cmd\": \"activate\", \"package_id\": \"my_pack\"}'}"

# 查询所有资源包
ros2 topic pub --once /eyes/resource std_msgs/msg/String \
  "{data: '{\"cmd\": \"query\"}'}"

# 删除资源包
ros2 topic pub --once /eyes/resource std_msgs/msg/String \
  "{data: '{\"cmd\": \"delete\", \"package_id\": \"my_pack\"}'}"

# 设置双眼表情（ID=2）
ros2 topic pub --once /eyes/expression std_msgs/msg/String \
  "{data: '{\"target\": \"both\", \"expression_id\": 2}'}"

# 仅设置左眼表情
ros2 topic pub --once /eyes/expression std_msgs/msg/String \
  "{data: '{\"target\": \"left\", \"expression_id\": 1}'}"

# 设置亮度 80%
ros2 topic pub --once /eyes/brightness std_msgs/msg/Int32 "{data: 80}"

# 监听资源包操作反馈
ros2 topic echo /eyes/resource_status

# 监听当前眼睛状态
ros2 topic echo /eyes/state
