声源定位（/audio/doa） ​

检测到声源时发布方向角信息。以机器人正前方为 0°，向左为正，向右为负，范围 (-180°, 180°]。

消息类型： std_msgs/msg/String（JSON 格式）

json
{
  "stamp": {
    "sec": 1745000000,
    "nanosec": 123456789
  },
  "angle": 35.5
}

ASR 控制（/asr/cmd） ​

通过 /asr/cmd 停止或重启 ASR 识别，适用于需要主动停止/重启机器人语音对话的场景。

消息类型： std_msgs/msg/String（JSON 格式）

cmd说明
mute停止 ASR 识别；期间不再发布 /asr/result，也不会触发后续 /llm/response 与 /tts/text 发布
unmute重启 ASR 识别
json
{"cmd": "mute"}
{"cmd": "unmute"}

LLM 回复文本（/llm/response） ​

机器人内部 LLM 模块推理完成后，将回复文本以流式追加方式发布到 /llm/response，每包携带本次新增的文本片段，is_end: true 标识本轮回复结束。

下游模块（如 TTS、界面显示）订阅此话题并拼接 delta 字段即可还原完整回复。

消息类型： std_msgs/msg/String（JSON 格式）

json
{
  "stamp": {
    "sec": 1745000000,
    "nanosec": 123456789
  },
  "start_time": {
    "sec": 1745000000,
    "nanosec": 0
  },
  "session_id": "llm_001",
  "delta": "今天天气不错，",
  "is_end": false
}

字段类型说明
stamp.secint本包发布时间戳（秒）
stamp.nanosecint本包发布时间戳（纳秒）
start_time.secint本轮回复开始时间戳（秒）
start_time.nanosecint本轮回复开始时间戳（纳秒）
session_idstring本轮对话会话 ID，同一轮回复所有包共享同一值
deltastring本包新增的文本片段（追加到已有内容末尾）
is_endboolfalse 表示回复未结束；true 表示本轮回复完全结束

{"stamp": {"sec": 1745000000, "nanosec": 200000000}, "start_time": {"sec": 1745000000, "nanosec": 0}, "session_id": "llm_001", "delta": "不错，",      "is_end": false}

TTS 语音合成（/tts/text） ​

机器人合成并播报语音时，将正在播报的文本以流式追加方式发布到 /tts/text，每包携带本次新增的文本片段，is_end: true 标识本句结束。订阅此话题即可实时获取机器人当前播报内容（如用于字幕显示、对话记录）。

消息类型： std_msgs/msg/String（JSON 格式）

json
{
  "stamp": {
    "sec": 1745000000,
    "nanosec": 123456789
  },
  "text": "你好，我是机器人。",
  "is_end": true,
  "session_id": "tts_001"
}

stamp.secint本包发布时间戳（秒）
stamp.nanosecint本包发布时间戳（纳秒）
textstring本次播报的文本片段
is_endboolfalse 表示后续还有更多文本；true 表示本句结束
session_idstring会话 ID，用于关联同一句话的多个分段

播放音频文件（/audio/play） ​

播放本地存储的音频文件（WAV / MP3）。

消息类型： std_msgs/msg/String（JSON 格式）

json
{
  "file_path": "/home/user/sounds/greeting.wav",
  "volume": 80,
  "loop": false
}
1
2
3
4
5
字段类型必填说明
file_pathstring否音频文件绝对路径，支持 WAV / MP3；cmd 为 stop 时可省略
volumeint否播放音量，范围 0–100，缺省使用系统当前音量
loopbool否是否循环播放，默认 false
cmdstring否控制指令："stop" 立即停止当前播放

停止播放示例：

json
{"cmd": "stop"}
1

status说明
playing正在播放
finished播放完成
interrupted被打断（收到 stop 指令）
fail播放失败，见 fail_reason（如 "file_not_found"、"format_unsupported"）

发送新的 /audio/play 指令时，若当前正在播放，则自动中断当前播放并开始新文件。

示例命令 ​

bash
# 获取 DOA 声源定位角度
ros2 topic echo /audio/doa

# 监听 ASR 识别结果
ros2 topic echo /asr/result

# ASR 静音（停止语音对话）
ros2 topic pub --once /asr/cmd std_msgs/msg/String "{data: '{\"cmd\": \"mute\"}'}"

# ASR 恢复识别（重启语音对话）
ros2 topic pub --once /asr/cmd std_msgs/msg/String "{data: '{\"cmd\": \"unmute\"}'}"

# 监听 LLM 流式回复
ros2 topic echo /llm/response

# 监听机器人正在播报的 TTS 文本
ros2 topic echo /tts/text

# 监听 TTS 播放状态
ros2 topic echo /tts/status

# 播放本地音频文件
ros2 topic pub --once /audio/play std_msgs/msg/String \
  "{data: '{\"file_path\": \"/home/user/sounds/greeting.wav\", \"volume\": 80}'}"

# 停止音频播放
ros2 topic pub --once /audio/play std_msgs/msg/String \
  "{data: '{\"cmd\": \"stop\"}'}"

# 监听音频播放状态
ros2 topic echo /audio/status
