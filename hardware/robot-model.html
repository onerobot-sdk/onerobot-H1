H1 机器人模型 ​

H1 Description v1.4 基于结构团队导出的含左右自研夹爪完整模型，提供整机 URDF 与轻量化 STL 网格，可用于结构查看、坐标关系理解和 H1 应用开发。v1.3（已验证的拼接模型）和 v1.2 继续保留用于历史版本追溯。

网页滑块仅用于预览模型几何和关节运动，不连接 ROS 2、不读取真机状态，也不能控制真实机器人。

文件结构 ​

解压 h1_description_v1.4.zip 后，目录结构如下：

URDF 长度单位为米，转动关节位置单位为弧度。网格通过 package://h1_description/meshes/... 引用；集成时请将 package 名称配置为 h1_description，并让该名称映射到包含 urdf/ 和 meshes/ 的模型目录。

关节统计 ​

  • 46 个连杆，对应 46 个独立 STL 网格；
  • 45 个关节，其中 43 个可动；
  • 网页保留双臂 14、头部 2、升降 1，共 17 个直接关节控制；
  • 网页提供“左夹爪开合”和“右夹爪开合”两个联动控件，每个控件同时驱动对应夹爪的八个连杆关节；0% 为结构模型的闭合零位，100% 为张开位置；
  • 页面共提供 19 个主要调节控件；
  • 驱动轮和脚轮的其余 10 个 continuous 关节保留在 URDF 中，但不显示手动滑块。

H1 模型专用使用条款 ​

  1. 本模型文件仅允许用于 H1 机器人的开发和测试。
  2. 使用者可以为了上述目的在本地复制、修改或转换模型格式。
  3. 禁止将原始或修改后的模型文件用于商业用途。
  4. 禁止向任何第三方再次分发原始或修改后的模型文件。
