手势识别 ​

手势识别会发布当前识别到的手势结果，并在启动时发布一次当前支持的手势列表。业务侧可以直接订阅识别结果，也可以通过任务编排的 wait_for_gesture 任务等待指定手势触发。

页面导览 ​

使用场景主要入口建议用法
实时监听手势/gesture/result业务节点订阅 JSON 字符串，按 gesture 和 score 触发动作
获取支持列表/gesture/types节点启动后订阅，确认当前可用手势
编排任务等待手势/task_orchestrator/submit提交 wait_for_gesture，等待目标手势后进入下一步
调试识别质量score、bbox查看置信度和手部检测框，定位姿态、距离、光照问题

接口总览 ​

Topic消息类型QoS发布时机说明
/gesture/resultstd_msgs/msg/String默认可靠订阅即可识别到有效手势后发布输出手势名称、置信度和检测框
/gesture/typesstd_msgs/msg/StringRELIABLE + TRANSIENT_LOCAL，depth=1节点启动时发布一次输出当前支持的全部手势名称，后启动订阅者也可收到

监听命令：

bash
ros2 topic echo /gesture/result
ros2 topic echo /gesture/types

支持手势 ​

当前 /gesture/types 发布的支持列表为：

json
{
  "supported_gestures": ["yeah", "thumbup", "okay", "rock", "heart", "stop", "mute", "wave"]
}
1
2
3
手势名含义类型触发条件
yeah比耶/胜利静态稳定保持：高分 2 帧或低分 5 帧；触发后 3s 冷却
thumbup竖大拇指/点赞静态稳定保持；score >= 0.9 才计入；触发后 3s 冷却
okayOK 手势静态稳定保持；score >= 0.9 才计入；触发后 3s 冷却
rock摇滚手势静态稳定保持；score >= 0.9 才计入；触发后 5s 冷却
heart比心静态稳定保持；触发后 3s 冷却
stop停止/张开手掌静态稳定保持；触发后 3s 冷却
mute嘘/食指竖在嘴前静态稳定保持；触发后 3s 冷却
wave挥手打招呼动态手心朝前 + 左右往复运动，至少 2 次反转；触发后 3s 冷却

禁用手势

come 当前已禁用，不在 supported_gestures 列表中，也不会触发。业务侧不要把 come 作为有效入口。

任务编排接入 ​

任务编排已支持 wait_for_gesture。该任务订阅 /gesture/result，当收到目标手势且满足过滤条件后返回 succeeded；取消或超时会返回对应终态。

text
手势识别
  -> /gesture/result
  -> task_orchestrator wait_for_gesture
  -> /task_orchestrator/status

任务参数 ​

字段类型必填默认值说明
task_typestring是无固定为 wait_for_gesture
gesturestring是无等待的手势名，例如 thumbup、wave
min_scorefloat否0.0业务侧额外置信度阈值，范围 0.0 到 1.0
directionstring否空字符串可选方向过滤；为空时不限制方向
timeout_msint否30000等待超时时间，单位毫秒

提交示例 ​

等待点赞手势，要求置信度不低于 0.9：

bash
ros2 topic pub --once /task_orchestrator/submit std_msgs/msg/String \
  "data: '{\"task_type\":\"wait_for_gesture\",\"gesture\":\"thumbup\",\"min_score\":0.9,\"timeout_ms\":30000}'"

接入要点 ​

要点说明
以 gesture 为主触发字段score 用于置信度过滤，不建议用 bbox 直接判断手势类型
优先读取 /gesture/types该 topic 使用 TRANSIENT_LOCAL，业务节点后启动也能拿到支持列表
静态手势已做稳定保持节点侧已包含稳定帧和冷却逻辑，业务侧通常不需要再做高频去抖
高置信手势已有节点侧过滤thumbup、okay、rock 已要求 score >= 0.9 才计入
wave 是动态手势需要手心朝前并完成左右往复反转，调试时不要只保持静态姿势
direction 为预留字段当前所有手势均返回空字符串，业务侧暂不需要依赖该字段

常见问题排查 ​

现象可能原因排查建议
没有手势输出未满足稳定保持、置信度阈值或处于冷却期保持姿态更稳定，检查 score，等待冷却结束
thumbup / okay / rock 不触发score < 0.9调整手势姿态、距离、光照和遮挡
rock 触发不频繁冷却时间为 5s按 5s 冷却设计交互，不要连续高频提交任务
wave 不触发手心未朝前或左右反转不足保持手心朝前，增加左右往复幅度
wait_for_gesture 超时目标手势不匹配、阈值过高或手势已禁用确认 gesture 拼写，降低 min_score，查看 /gesture/types
订阅 /gesture/types 没收到QoS 不匹配或手势识别未启动使用 RELIABLE + TRANSIENT_LOCAL 订阅配置，确认手势识别已启动
