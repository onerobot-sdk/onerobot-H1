MoveIt2 运动控制 ​

提供标准的 MoveIt2 动作接口，用于双臂的轨迹规划与执行。支持关节空间目标、位姿目标、笛卡尔路径，以及预置命名姿态。

本页的规划组、关节名与末端 link 对应 A1 双臂 MoveIt 配置。使用前确认设备安装并启动了配套 MoveIt 服务；这些名称与 H1 v1.4 整机显示模型不同，不能互换。

本页代码块默认收起，点击标题可展开或收起；展开后可复制完整内容。

接口总览 ​

接口消息类型说明
/move_actionmoveit_msgs/action/MoveGroupMoveGroup 动作服务器（规划 + 执行）
/execute_trajectorymoveit_msgs/action/ExecuteTrajectory执行预先规划好的轨迹

/move_action — MoveGroup 动作 ​

规划并执行运动轨迹，是 MoveIt2 最核心的动作接口。

Goal 字段：

字段用途
request规划组、目标约束、起点、规划时间与缩放
planning_options.plan_onlytrue 仅规划；false 规划后执行
planning_options.planning_scene_diff.is_diff使用现有规划场景，并应用请求中的差异

Result 字段：

字段用途
error_code.valMoveIt 业务错误码
trajectory_start规划使用的起点状态
planned_trajectory规划轨迹；可交给 /execute_trajectory
executed_trajectory执行结果中的轨迹，部分执行链路可能不填充
planning_time规划耗时

应同时检查 Action 终态和 error_code.val，不要以 executed_trajectory 是否非空作为唯一成功依据。下方完整 Action 程序构造实际 Goal，并检查接收、反馈和结果。

/execute_trajectory — 轨迹执行动作 ​

执行预规划的轨迹，跳过规划阶段。

完整 Action 示例先通过 /move_action 获取规划轨迹，打印整条路径，再把同一个 RobotTrajectory 放入 ExecuteTrajectory.Goal.trajectory。不需要手写绝对角度或补全轨迹点。服务器仍会校验轨迹起点是否与执行时的真实状态一致。

字段用途
Goal.trajectory已规划的 RobotTrajectory
Goal.controller_names可选控制器列表；空列表由 MoveIt 选择
Result.error_code.val执行的 MoveIt 业务错误码
Feedback.state执行状态文本

规划组参考 ​

规划组自由度末端 link说明
left_arm7left_link7左臂
right_arm7right_link7右臂
both_arms14left_link7 + right_link7双臂联合

关节命名约定 ​

左臂关节名为 joint1-l ~ joint7-l，右臂为 joint1-r ~ joint7-r。下发轨迹的 joint_names 必须使用这套带后缀的名称。每臂 7 个均为转动关节；joint7-l / joint7-r 不是固定关节。H1 v1.4 整机 URDF 使用 left_arm_joint_1…7 / right_arm_joint_1…7，两者的用途与数据入口不同。

预置命名姿态 ​

可直接用名字作为目标，无需手动指定关节角：

名称适用组含义
homeleft_arm / right_arm单臂归零位
readyleft_arm / right_arm单臂常用准备位
dual_homeboth_arms双臂同时归零
dual_readyboth_arms双臂同时进入准备位

下方 move_group_demo.cpp 是含 main() 的完整程序，goal:=named 使用 setNamedTarget() → plan() → execute(已规划轨迹)。单臂默认命名目标为 ready，双臂为 dual_ready；可用 named_target 改为 home 或 dual_home。所有命名目标默认只规划。

关键消息类型 ​

moveit_msgs/msg/MotionPlanRequest ​

字段类型消息初值MoveGroupInterface 默认值说明
group_namestring空字符串由构造时的组名确定规划组名称，如 "left_arm"、"right_arm"、"both_arms"
num_planning_attemptsint3201规划尝试次数；执行示例建议显式设置
allowed_planning_timefloat640.05.0允许的最大规划时间（秒）；执行示例建议显式设置
max_velocity_scaling_factorfloat640.00.1有效显式范围为 (0, 1]；0 或越界值由 MoveIt 使用内部默认值处理
max_acceleration_scaling_factorfloat640.00.1有效显式范围为 (0, 1]；0 或越界值由 MoveIt 使用内部默认值处理

消息初值、客户端默认值和服务端对零值的处理是不同层级。执行运动时应显式设置缩放，不要依赖 0.0 的内部默认语义。

moveit_msgs/msg/RobotTrajectory ​

字段类型说明
joint_trajectorytrajectory_msgs/JointTrajectory关节轨迹
multi_dof_joint_trajectorytrajectory_msgs/MultiDOFJointTrajectory多自由度关节轨迹

本页示例的兼容性结论如下：

系统与架构ROS / MoveIt兼容性结论

Ubuntu 24.04 / x86_64ROS 2 Jazzy / MoveIt 2.12.4客户端示例已验证，可编译运行。

以上结论覆盖客户端示例的编译、规划与模拟执行；真机驱动和运动能力仍需在目标设备上验证。本页安装命令和环境脚本按 Jazzy 编写，连接机器人时应优先使用与服务端一致的 ROS 2 发行版和 moveit_msgs 消息版本。

迁移至 Humble 时，高级 C++ 示例需调整头文件、轨迹成员和笛卡尔路径参数。以 MoveIt 2.5.9 接口为例，应使用 .h、Plan::trajectory_，并为 computeCartesianPath() 提供 jump_threshold；仅替换安装命令中的发行版名称不能直接编译当前示例。C++／Python Action 示例也需核对目标版本的消息与客户端 API。

Jazzy 配套 arm_moveit.launch.py 应包含 move_group 的插件库预加载修复，以避免停止时发生段错误；该修复尚未完成真机验证。

运行前，机器人需已经启动匹配 A1 配置的 MoveIt 服务，/move_action、/execute_trajectory 和真实 /joint_states 可用。开发机与机器人需使用一致的 ROS 域和中间件配置；在另一台机器运行时也要同步系统时钟。本页程序作为客户端运行，不启动驱动、MoveIt 服务或 fake joint states。

C++ 示例 ​

本节包含两个可独立运行的 C++ 程序，以及一个为高级接口准备模型参数的 Python 工具：

文件实现的功能输入与输出
src/move_group_demo.cpp使用 MoveGroupInterface 完成关节目标、命名姿态、位姿目标和单臂笛卡尔路径规划；支持左臂、右臂和双臂组，笛卡尔路径限单臂使用。可执行本次规划得到的完整轨迹。通过 --params-file 加载模型参数；通过 group、goal、delta、named_target 选择目标。输出轨迹关节名、各点时间和关节角；不完整笛卡尔路径报告失败。
src/action_demo.cpp直接调用标准 Action 接口：根据当前关节反馈生成小幅关节目标，通过 /move_action 只规划，再按需将同一条轨迹交给 /execute_trajectory。处理 Goal 接收、反馈、Action 终态和 MoveIt 错误码。通过 group、delta 选择目标，订阅 /joint_states 获取所选组的完整、新鲜关节状态。输出 Action 反馈和规划轨迹；可直接使用服务端模型配置。
scripts/read_moveit_params.py为 move_group_demo 读取正在运行的 /move_group 的 URDF、SRDF、运动学和关节限位参数，生成客户端模型参数文件。通过 --output 指定 YAML 路径，默认写入 /tmp/onero_moveit_params.yaml；输出写入的参数数量和文件位置。

两个 C++ 程序默认只规划，速度与加速度缩放均为 0.05。默认关节目标为左臂第一关节在当前角度上增加 0.02 rad；启用 execute:=true 后，还需审查输出轨迹并输入 EXECUTE 才会执行。

高级接口：关节、位姿、命名目标和笛卡尔路径 ​

文件：src/move_group_demo.cpp

展开 / 收起 src/move_group_demo.cpp 完整代码
cpp
#include <cmath>
#include <iostream>
#include <map>
#include <memory>
#include <stdexcept>
#include <string>
#include <thread>
#include <vector>

#include <Eigen/Geometry>
#include <geometry_msgs/msg/pose.hpp>
#include <moveit/move_group_interface/move_group_interface.hpp>
#include <moveit_msgs/msg/move_it_error_codes.hpp>
#include <rclcpp/rclcpp.hpp>

using MoveGroup = moveit::planning_interface::MoveGroupInterface;

geometry_msgs::msg::Pose currentPose(
    const moveit::core::RobotState& state, const std::string& link) {
    const auto& transform = state.getGlobalLinkTransform(link);
    const Eigen::Quaterniond quaternion(transform.rotation());
    geometry_msgs::msg::Pose pose;
    pose.position.x = transform.translation().x();
    pose.position.y = transform.translation().y();
    pose.position.z = transform.translation().z();
    pose.orientation.x = quaternion.x();
    pose.orientation.y = quaternion.y();
    pose.orientation.z = quaternion.z();
    pose.orientation.w = quaternion.w();
    return pose;
}

void printTrajectory(const moveit_msgs::msg::RobotTrajectory& trajectory) {
    const auto& joints = trajectory.joint_trajectory;
    if (joints.points.empty()) throw std::runtime_error("Planner returned an empty trajectory");
    std::cout << "joint_names:";
    for (const auto& name : joints.joint_names) std::cout << ' ' << name;
    std::cout << '\n';
    for (const auto& point : joints.points) {
        std::cout << "t=" << point.time_from_start.sec + point.time_from_start.nanosec * 1e-9;
        for (double position : point.positions) std::cout << ' ' << position;
        std::cout << '\n';
    }
}

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    auto node = std::make_shared<rclcpp::Node>(
        "onero_move_group_demo",
        rclcpp::NodeOptions().automatically_declare_parameters_from_overrides(true));
    rclcpp::executors::SingleThreadedExecutor executor;
    executor.add_node(node);
    std::thread spinner([&executor] { executor.spin(); });
    int exit_code = 0;
    try {
        const auto group_name = node->get_parameter_or<std::string>("group", "left_arm");
        const auto goal_type = node->get_parameter_or<std::string>("goal", "joint");
        const double delta = node->get_parameter_or<double>("delta", 0.02);
        const bool execute = node->get_parameter_or<bool>("execute", false);
        if (group_name != "left_arm" && group_name != "right_arm" && group_name != "both_arms") {
            throw std::runtime_error("group must be left_arm, right_arm, or both_arms");
        }
        if (!std::isfinite(delta) || std::abs(delta) > 0.05) {
            throw std::runtime_error("delta must be finite and within +/-0.05 rad");
        }

        // node 已由 shared_ptr 托管；背景 executor 持续处理关节反馈。
        MoveGroup group(node, group_name, nullptr, rclcpp::Duration::from_seconds(10.0));
        group.setPlanningTime(5.0);
        group.setNumPlanningAttempts(1);
        group.setMaxVelocityScalingFactor(0.05);
        group.setMaxAccelerationScalingFactor(0.05);
        const auto state = group.getCurrentState(10.0);
        if (!state) throw std::runtime_error("No complete current robot state within 10 seconds");
        state->update();
        group.setStartState(*state);
        group.setPoseReferenceFrame(group.getRobotModel()->getModelFrame());

        MoveGroup::Plan plan;
        if (goal_type == "joint") {
            // 名称映射包含当前组的全部关节，不依赖双臂 vector 的排列顺序。
            std::map<std::string, double> targets;
            for (const auto& name : group.getJointNames()) {
                const double value = state->getVariablePosition(name);
                if (!std::isfinite(value)) throw std::runtime_error("Non-finite joint feedback");
                targets[name] = value;
            }
            if (group_name != "right_arm") targets.at("joint1-l") += delta;
            if (group_name != "left_arm") targets.at("joint1-r") +=
                group_name == "both_arms" ? -delta : delta;
            if (!group.setJointValueTarget(targets)) throw std::runtime_error("Invalid joint target");
        } else if (goal_type == "named") {
            const auto name = node->get_parameter_or<std::string>(
                "named_target", group_name == "both_arms" ? "dual_ready" : "ready");
            if (!group.setNamedTarget(name)) throw std::runtime_error("Unknown named target: " + name);
        } else if (goal_type == "pose" || goal_type == "cartesian") {
            if (goal_type == "cartesian" && group_name == "both_arms") {
                throw std::runtime_error("Cartesian example requires a single-arm group");
            }
            std::vector<std::string> tips;
            if (group_name != "right_arm") tips.push_back("left_link7");
            if (group_name != "left_arm") tips.push_back("right_link7");
            for (const auto& tip : tips) {
                auto pose = currentPose(*state, tip);
                pose.position.z += 0.005;  // 从当前 FK 位姿向上移动 5 mm。
                if (goal_type == "pose") {
                    if (!group.setPoseTarget(pose, tip)) throw std::runtime_error("Invalid pose target");
                } else {
                    group.setEndEffectorLink(tip);
                    moveit_msgs::msg::MoveItErrorCodes error;
                    const double fraction = group.computeCartesianPath(
                        {currentPose(*state, tip), pose}, 0.001, plan.trajectory, true, &error);
                    std::cout << "fraction=" << fraction << " error_code=" << error.val << '\n';
                    if (error.val != moveit_msgs::msg::MoveItErrorCodes::SUCCESS ||
                        !std::isfinite(fraction) || std::abs(fraction - 1.0) > 1e-6) {
                        throw std::runtime_error("Cartesian path is incomplete; execution skipped");
                    }
                }
            }
        } else {
            throw std::runtime_error("goal must be joint, named, pose, or cartesian");
        }

        if (goal_type != "cartesian") {
            const auto result = group.plan(plan);
            if (result != moveit::core::MoveItErrorCode::SUCCESS) {
                throw std::runtime_error("Planning failed: " + std::to_string(result.val));
            }
        }
        printTrajectory(plan.trajectory);
        if (execute) {
            std::cout << "Review the entire trajectory and clear the workspace. Type EXECUTE: " << std::flush;
            std::string confirmation;
            if (!std::getline(std::cin, confirmation) || confirmation != "EXECUTE") {
                throw std::runtime_error("Execution not confirmed");
            }
            // 执行这次打印的轨迹；不用 move() 重新规划。
            const auto result = group.execute(plan.trajectory);
            if (result != moveit::core::MoveItErrorCode::SUCCESS) {
                throw std::runtime_error("Execution failed: " + std::to_string(result.val));
            }
            std::cout << "Execution action succeeded; verify actual joint feedback.\n";
        } else {
            std::cout << "Plan-only complete; no execution goal was sent.\n";
        }
    } catch (const std::exception& error) {
        std::cerr << error.what() << '\n';
        exit_code = 1;
    }
    // MoveGroupInterface 在离开 try 作用域时先析构，然后停止 executor。
    executor.cancel();
    spinner.join();
    node.reset();
    rclcpp::shutdown();
    return exit_code;
}

#!/usr/bin/env python3
"""Copy the running move_group model parameters into a client YAML file."""
import argparse
from pathlib import Path

import rclpy
from rcl_interfaces.msg import ParameterType, ParameterValue
from rcl_interfaces.srv import GetParameters, ListParameters
from rclpy.node import Node
from rclpy.parameter import parameter_value_to_python
import yaml


def request(node, service_type, endpoint, message):
    client = node.create_client(service_type, endpoint)
    try:
        if not client.wait_for_service(timeout_sec=10.0):
            raise RuntimeError(f"{endpoint} unavailable; start the matching MoveIt service first")
        future = client.call_async(message)
        rclpy.spin_until_future_complete(node, future, timeout_sec=10.0)
        if not future.done() or future.result() is None:
            raise RuntimeError(f"{endpoint} timed out")
        return future.result()
    finally:
        node.destroy_client(client)


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--output", default="/tmp/onero_moveit_params.yaml")
    args = parser.parse_args()
    rclpy.init(args=[])
    node = Node("onero_moveit_parameter_reader")
    try:
        listing = ListParameters.Request()
        listing.prefixes = ["robot_description_kinematics", "robot_description_planning"]
        listing.depth = 0
        names = ["robot_description", "robot_description_semantic"]
        names += request(node, ListParameters, "/move_group/list_parameters", listing).result.names
        query = GetParameters.Request()
        query.names = names
        values = request(node, GetParameters, "/move_group/get_parameters", query).values
        if len(values) != len(names):
            # rclcpp may return an empty batch if an optional parameter is uninitialized.
            # Read separately so initialized model parameters are still preserved.
            values = []
            for name in names:
                query.names = [name]
                result = request(node, GetParameters, "/move_group/get_parameters", query).values
                values.append(result[0] if result else ParameterValue())
        parameters = {
            name: parameter_value_to_python(value)
            for name, value in zip(names, values)
            if value.type != ParameterType.PARAMETER_NOT_SET
        }
        # ROS parameter YAML cannot infer an element type for an empty array.
        parameters = {name: value for name, value in parameters.items() if value != []}
        for name in names[:2]:
            if not isinstance(parameters.get(name), str) or not parameters[name]:
                raise RuntimeError(f"{name} is missing or empty on /move_group")
        path = Path(args.output)
        path.write_text(yaml.safe_dump({"/**": {"ros__parameters": parameters}}), encoding="utf-8")
        print(f"Wrote {len(parameters)} parameters to {path}")
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == "__main__":
    main()

#include <chrono>
#include <cmath>
#include <iostream>
#include <map>
#include <memory>
#include <stdexcept>
#include <string>
#include <vector>

#include <moveit_msgs/action/execute_trajectory.hpp>
#include <moveit_msgs/action/move_group.hpp>
#include <moveit_msgs/msg/constraints.hpp>
#include <moveit_msgs/msg/joint_constraint.hpp>
#include <moveit_msgs/msg/move_it_error_codes.hpp>
#include <rclcpp/rclcpp.hpp>
#include <rclcpp_action/rclcpp_action.hpp>
#include <sensor_msgs/msg/joint_state.hpp>

using namespace std::chrono_literals;
using Clock = std::chrono::steady_clock;
using MoveGroup = moveit_msgs::action::MoveGroup;
using ExecuteTrajectory = moveit_msgs::action::ExecuteTrajectory;

template<class Action>
std::shared_ptr<typename Action::Result> callAction(
    const rclcpp::Node::SharedPtr& node, const std::string& endpoint,
    const typename Action::Goal& goal) {
    auto client = rclcpp_action::create_client<Action>(node, endpoint);
    if (!client->wait_for_action_server(10s)) throw std::runtime_error(endpoint + " unavailable");
    typename rclcpp_action::Client<Action>::SendGoalOptions options;
    options.feedback_callback = [](auto, const auto feedback) {
        // C++ 回调收到 Feedback 本体，直接访问 state。
        std::cout << "feedback: " << feedback->state << '\n';
    };
    auto accepted = client->async_send_goal(goal, options);
    if (rclcpp::spin_until_future_complete(node, accepted, 10s) != rclcpp::FutureReturnCode::SUCCESS) {
        throw std::runtime_error(endpoint + " goal response timeout");
    }
    const auto handle = accepted.get();
    if (!handle) throw std::runtime_error(endpoint + " goal rejected");
    auto finished = client->async_get_result(handle);
    if (rclcpp::spin_until_future_complete(node, finished, 60s) != rclcpp::FutureReturnCode::SUCCESS) {
        throw std::runtime_error(endpoint + " result timeout; timeout does not mean canceled");
    }
    const auto wrapped = finished.get();
    if (wrapped.code != rclcpp_action::ResultCode::SUCCEEDED || !wrapped.result ||
        wrapped.result->error_code.val != moveit_msgs::msg::MoveItErrorCodes::SUCCESS) {
        throw std::runtime_error(endpoint + " failed, error_code=" +
            std::to_string(wrapped.result ? wrapped.result->error_code.val : 0));
    }
    return wrapped.result;
}

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    auto node = std::make_shared<rclcpp::Node>("onero_moveit_action_demo");
    const auto group = node->declare_parameter<std::string>("group", "left_arm");
    const double delta = node->declare_parameter<double>("delta", 0.02);
    const bool execute = node->declare_parameter<bool>("execute", false);
    int exit_code = 0;
    try {
        if (group != "left_arm" && group != "right_arm" && group != "both_arms") {
            throw std::runtime_error("Invalid planning group");
        }
        if (!std::isfinite(delta) || std::abs(delta) > 0.05) {
            throw std::runtime_error("delta must be finite and within +/-0.05 rad");
        }
        std::vector<std::string> names;
        for (const auto& suffix : std::vector<std::string>{"l", "r"}) {
            if ((group == "left_arm" && suffix == "r") || (group == "right_arm" && suffix == "l")) continue;
            for (int i = 1; i <= 7; ++i) names.push_back("joint" + std::to_string(i) + "-" + suffix);
        }
        struct Sample { double position; Clock::time_point received; };
        std::map<std::string, Sample> state;
        auto subscription = node->create_subscription<sensor_msgs::msg::JointState>(
            "/joint_states", rclcpp::SensorDataQoS(), [&](const sensor_msgs::msg::JointState& msg) {
                const double age = (node->now() - rclcpp::Time(msg.header.stamp)).seconds();
                if (age < 0.0 || age > 0.5) return;
                const auto received = Clock::now();
                for (std::size_t i = 0; i < msg.name.size() && i < msg.position.size(); ++i) {
                    if (std::isfinite(msg.position[i])) state[msg.name[i]] = {msg.position[i], received};
                }
            });
        auto complete = [&] {
            for (const auto& name : names) {
                if (!state.count(name) || Clock::now() - state.at(name).received > 500ms) return false;
            }
            return true;
        };
        const auto deadline = Clock::now() + 10s;
        while (rclcpp::ok() && !complete() && Clock::now() < deadline) rclcpp::spin_some(node);
        if (!complete()) throw std::runtime_error("Missing or stale joint feedback");

        MoveGroup::Goal goal;
        goal.request.group_name = group;
        goal.request.num_planning_attempts = 1;
        goal.request.allowed_planning_time = 5.0;
        goal.request.max_velocity_scaling_factor = 0.05;
        goal.request.max_acceleration_scaling_factor = 0.05;
        goal.request.start_state.is_diff = true;
        goal.planning_options.plan_only = true;
        goal.planning_options.planning_scene_diff.is_diff = true;
        goal.planning_options.planning_scene_diff.robot_state.is_diff = true;
        moveit_msgs::msg::Constraints constraints;
        for (const auto& name : names) {
            moveit_msgs::msg::JointConstraint joint;
            joint.joint_name = name;
            joint.position = state.at(name).position;
            if (name == "joint1-l") joint.position += delta;
            if (name == "joint1-r") joint.position += group == "both_arms" ? -delta : delta;
            joint.tolerance_above = joint.tolerance_below = 0.001;
            joint.weight = 1.0;
            constraints.joint_constraints.push_back(joint);
        }
        goal.request.goal_constraints.push_back(constraints);
        const auto planned = callAction<MoveGroup>(node, "/move_action", goal);
        const auto& trajectory = planned->planned_trajectory.joint_trajectory;
        if (trajectory.points.empty()) throw std::runtime_error("Empty planned trajectory");
        std::cout << "joint_names:";
        for (const auto& name : trajectory.joint_names) std::cout << ' ' << name;
        std::cout << '\n';
        for (const auto& point : trajectory.points) {
            std::cout << "t=" << point.time_from_start.sec + point.time_from_start.nanosec * 1e-9;
            for (double position : point.positions) std::cout << ' ' << position;
            std::cout << '\n';
        }
        if (execute) {
            std::cout << "Review the entire trajectory and clear the workspace. Type EXECUTE: " << std::flush;
            std::string confirmation;
            if (!std::getline(std::cin, confirmation) || confirmation != "EXECUTE") {
                throw std::runtime_error("Execution not confirmed");
            }
            ExecuteTrajectory::Goal execution;
            execution.trajectory = planned->planned_trajectory;
            callAction<ExecuteTrajectory>(node, "/execute_trajectory", execution);
            std::cout << "Execution action succeeded; verify actual joint feedback.\n";
        } else {
            std::cout << "Plan-only complete; no execution goal was sent.\n";
        }
    } catch (const std::exception& error) {
        std::cerr << error.what() << '\n';
        exit_code = 1;
    }
    node.reset();
    rclcpp::shutdown();
    return exit_code;
}

展开 / 收起 scripts/moveit_action_demo.py 完整代码
py
#!/usr/bin/env python3
"""Plan a small joint target; execute the reviewed plan only with --execute."""
import argparse
import math
import time

import rclpy
from action_msgs.msg import GoalStatus
from moveit_msgs.action import ExecuteTrajectory, MoveGroup
from moveit_msgs.msg import Constraints, JointConstraint, MoveItErrorCodes
from rclpy.action import ActionClient
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from sensor_msgs.msg import JointState


class MoveItClient(Node):
    def __init__(self):
        super().__init__("onero_moveit_python_demo")
        self.state = {}
        self.create_subscription(JointState, "/joint_states", self.on_state, qos_profile_sensor_data)

    def on_state(self, message):
        stamp = message.header.stamp.sec * 1_000_000_000 + message.header.stamp.nanosec
        age = (self.get_clock().now().nanoseconds - stamp) * 1e-9
        if age < 0.0 or age > 0.5:
            return
        received = time.monotonic()
        for name, position in zip(message.name, message.position):
            if math.isfinite(position):
                self.state[name] = (position, received)

    def current_positions(self, names):
        def complete():
            return all(name in self.state and time.monotonic() - self.state[name][1] <= 0.5 for name in names)

        deadline = time.monotonic() + 10.0
        while rclpy.ok() and not complete() and time.monotonic() < deadline:
            rclpy.spin_once(self, timeout_sec=0.02)
        if not complete():
            raise RuntimeError("Missing or stale joint feedback")
        return {name: self.state[name][0] for name in names}

    def wait(self, future, timeout):
        rclpy.spin_until_future_complete(self, future, timeout_sec=timeout)
        if not future.done():
            raise TimeoutError("Action timeout; timeout does not mean the goal was canceled")
        return future.result()

    def call_action(self, action_type, endpoint, goal):
        client = ActionClient(self, action_type, endpoint)
        try:
            if not client.wait_for_server(timeout_sec=10.0):
                raise RuntimeError(f"{endpoint} unavailable")
            handle = self.wait(client.send_goal_async(goal, feedback_callback=self.on_feedback), 10.0)
            if handle is None or not handle.accepted:
                raise RuntimeError(f"{endpoint} goal rejected")
            wrapped = self.wait(handle.get_result_async(), 60.0)
            if (wrapped.status != GoalStatus.STATUS_SUCCEEDED
                    or wrapped.result.error_code.val != MoveItErrorCodes.SUCCESS):
                raise RuntimeError(f"{endpoint}: status={wrapped.status}, error_code={wrapped.result.error_code.val}")
            return wrapped.result
        finally:
            client.destroy()

    def on_feedback(self, message):
        # Python 回调收到 FeedbackMessage 包装层。
        self.get_logger().info(f"feedback: {message.feedback.state}")

    def run(self, group, delta, execute):
        suffixes = ["l", "r"] if group == "both_arms" else ["l" if group == "left_arm" else "r"]
        names = [f"joint{i}-{suffix}" for suffix in suffixes for i in range(1, 8)]
        positions = self.current_positions(names)
        goal = MoveGroup.Goal()
        goal.request.group_name = group
        goal.request.num_planning_attempts = 1
        goal.request.allowed_planning_time = 5.0
        goal.request.max_velocity_scaling_factor = 0.05
        goal.request.max_acceleration_scaling_factor = 0.05
        goal.request.start_state.is_diff = True
        goal.planning_options.plan_only = True
        goal.planning_options.planning_scene_diff.is_diff = True
        goal.planning_options.planning_scene_diff.robot_state.is_diff = True
        constraints = Constraints()
        for name in names:
            joint = JointConstraint()
            joint.joint_name = name
            joint.position = positions[name]
            if name == "joint1-l":
                joint.position += delta
            if name == "joint1-r":
                joint.position += -delta if group == "both_arms" else delta
            joint.tolerance_above = joint.tolerance_below = 0.001
            joint.weight = 1.0
            constraints.joint_constraints.append(joint)
        goal.request.goal_constraints = [constraints]
        planned = self.call_action(MoveGroup, "/move_action", goal)
        trajectory = planned.planned_trajectory.joint_trajectory
        if not trajectory.points:
            raise RuntimeError("Empty planned trajectory")
        print("joint_names:", list(trajectory.joint_names))
        for point in trajectory.points:
            seconds = point.time_from_start.sec + point.time_from_start.nanosec * 1e-9
            print(f"t={seconds:.6f}", list(point.positions))
        if execute:
            confirmation = input("Review the entire trajectory and clear the workspace. Type EXECUTE: ")
            if confirmation != "EXECUTE":
                raise RuntimeError("Execution not confirmed")
            execution = ExecuteTrajectory.Goal()
            execution.trajectory = planned.planned_trajectory
            self.call_action(ExecuteTrajectory, "/execute_trajectory", execution)
            print("Execution action succeeded; verify actual joint feedback.")
        else:
            print("Plan-only complete; no execution goal was sent.")


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--group", choices=["left_arm", "right_arm", "both_arms"], default="left_arm")
    parser.add_argument("--delta", type=float, default=0.02)
    parser.add_argument("--execute", action="store_true")
    args = parser.parse_args()
    if not math.isfinite(args.delta) or abs(args.delta) > 0.05:
        parser.error("delta must be finite and within +/-0.05 rad")
    rclpy.init(args=[])
    node = MoveItClient()
    exit_code = 0
    try:
        node.run(args.group, args.delta, args.execute)
    except (RuntimeError, TimeoutError, EOFError) as error:
        node.get_logger().error(str(error))
        exit_code = 1
    finally:
        node.destroy_node()
        rclpy.shutdown()
    return exit_code


if __name__ == "__main__":
    raise SystemExit(main())

执行已规划轨迹 ​

速度缩放与限位 ​

当前发布的 MoveIt 配置中，关节级最大速度上限约 3.14 rad/s（180°/s），最大加速度上限约 5.0 rad/s²。它们是规划模型使用的配置上限，不是硬件性能认证值。max_velocity_scaling_factor 和 max_acceleration_scaling_factor 在这些配置上限的基础上缩放，不能独立保证运动安全或实际跟踪精度。

当前桥接配置中的 0.10 rad 是 FollowJointTrajectory 的关节终点到位阈值，不是应用保证的定位精度。Action 成功只表示执行链路按该阈值完成；需要更严格精度的应用还应读取完整、新鲜、有限值的真实关节反馈，并按自己的误差门槛再次判定。
