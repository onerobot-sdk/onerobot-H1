MoveIt2 运动控制 ​

提供标准的 MoveIt2 动作接口，用于双臂的轨迹规划与执行。支持关节空间目标、位姿目标、笛卡尔路径，以及预置命名姿态。

本页的规划组、关节名与末端 link 对应 A1 双臂 MoveIt 配置。使用前确认设备安装并启动了配套 MoveIt 服务；这些名称与 H1 v1.4 整机显示模型不同，不能互换。

接口总览 ​

接口消息类型说明
/move_actionmoveit_msgs/action/MoveGroupMoveGroup 动作服务器（规划 + 执行）
/execute_trajectorymoveit_msgs/action/ExecuteTrajectory执行预先规划好的轨迹

/move_action — MoveGroup 动作 ​

规划并执行运动轨迹，是 MoveIt2 最核心的动作接口。

PLANNING正在规划

error_code.val说明

99999通用失败 (FAILURE)
-1规划失败 (PLANNING_FAILED)
-3环境变化使运动计划失效 (MOTION_PLAN_INVALIDATED_BY_ENVIRONMENT_CHANGE)
-4控制失败 (CONTROL_FAILED)
-5无法获取传感器数据 (UNABLE_TO_AQUIRE_SENSOR_DATA)
-6超时 (TIMED_OUT)
-10起始状态碰撞 (START_STATE_IN_COLLISION)
-12目标状态碰撞 (GOAL_IN_COLLISION)

/execute_trajectory — 轨迹执行动作 ​

执行预规划的轨迹，跳过规划阶段。

下面仅展示消息结构。第一点必须来自最新、完整的真实关节状态，并在执行前检查关节名、点维度、时间顺序、限位、碰撞和整条路径；不要把示例中的固定绝对角度直接复制到姿态未知的机器人。

规划组参考 ​

规划组自由度末端 link说明
left_arm7left_link7左臂
right_arm7right_link7右臂
both_arms14left_link7 + right_link7双臂联合

关节命名约定 ​

左臂关节名为 joint1-l ~ joint7-l，右臂为 joint1-r ~ joint7-r。下发轨迹的 joint_names 必须使用这套带后缀的名称。每臂 7 个均为转动关节；joint7-l / joint7-r 不是固定关节。H1 v1.4 整机 URDF 使用 left_arm_joint_1…7 / right_arm_joint_1…7，两者的用途与数据入口不同。

预置命名姿态 ​

可直接用名字作为目标，无需手动指定关节角：

名称适用组含义
homeleft_arm / right_arm单臂归零位
readyleft_arm / right_arm单臂常用准备位
dual_homeboth_arms双臂同时归零
dual_readyboth_arms双臂同时进入准备位

关键消息类型 ​

moveit_msgs/msg/MotionPlanRequest ​

字段类型消息初值MoveGroupInterface 默认值说明
group_namestring空字符串由构造时的组名确定规划组名称，如 "left_arm"、"right_arm"、"both_arms"
num_planning_attemptsint3201规划尝试次数；执行示例建议显式设置
allowed_planning_timefloat640.05.0允许的最大规划时间（秒）；执行示例建议显式设置
max_velocity_scaling_factorfloat640.00.1有效显式范围为 (0, 1]；0 或越界值由 MoveIt 使用内部默认值处理
max_acceleration_scaling_factorfloat640.00.1有效显式范围为 (0, 1]；0 或越界值由 MoveIt 使用内部默认值处理

消息初值、客户端默认值和服务端对零值的处理是不同层级。执行运动时应显式设置缩放，不要依赖 0.0 的内部默认语义。

moveit_msgs/msg/RobotTrajectory ​

字段类型说明
joint_trajectorytrajectory_msgs/JointTrajectory关节轨迹
multi_dof_joint_trajectorytrajectory_msgs/MultiDOFJointTrajectory多自由度关节轨迹

C++ 示例 ​

高级接口（推荐） ​

cpp
#include <cmath>
#include <memory>
#include <stdexcept>
#include <string>
#include <vector>

#include <rclcpp/rclcpp.hpp>
#include <geometry_msgs/msg/pose.hpp>
#include <moveit/move_group_interface/move_group_interface.hpp>
#include <moveit_msgs/msg/move_it_error_codes.hpp>
#include <moveit_msgs/msg/robot_trajectory.hpp>

class MoveIt2Controller : public rclcpp::Node {
public:
    MoveIt2Controller() : Node("moveit2_controller") {}

    // 必须在 std::make_shared<MoveIt2Controller>() 完成后调用。
    void init() {
        move_group_ = std::make_shared<moveit::planning_interface::MoveGroupInterface>(
            shared_from_this(), "left_arm");
        move_group_->setPlanningTime(5.0);
        move_group_->setMaxVelocityScalingFactor(0.05);
        move_group_->setMaxAccelerationScalingFactor(0.05);
    }

    void executePoseGoal(const geometry_msgs::msg::Pose& target_pose) {
        if (!move_group_->setPoseTarget(target_pose)) {
            throw std::runtime_error("Invalid pose target");
        }
        planAndExecute();
    }

    void executeJointGoal(const std::vector<double>& joints) {
        // vector 按 getJointNames() 的运行时返回顺序赋值。
        if (!move_group_->setJointValueTarget(joints)) {
            throw std::runtime_error("Invalid joint target");
        }
        planAndExecute();
    }

    void executeNamedTarget(const std::string& name) {
        // 例如 "home" / "ready"
        if (!move_group_->setNamedTarget(name)) {
            throw std::runtime_error("Unknown named target: " + name);
        }
        planAndExecute();
    }

    void executeCartesianPath(const std::vector<geometry_msgs::msg::Pose>& waypoints) {
        moveit_msgs::msg::RobotTrajectory trajectory;
        moveit_msgs::msg::MoveItErrorCodes error_code;
        double fraction = move_group_->computeCartesianPath(
            waypoints, 0.01, trajectory, true, &error_code);

        const bool complete =
            error_code.val == moveit_msgs::msg::MoveItErrorCodes::SUCCESS &&
            std::isfinite(fraction) && std::abs(fraction - 1.0) < 1e-6 &&
            !trajectory.joint_trajectory.points.empty();
        if (!complete) {
            throw std::runtime_error("Cartesian path is incomplete");
        }
        if (move_group_->execute(trajectory) != moveit::core::MoveItErrorCode::SUCCESS) {
            throw std::runtime_error("Failed to execute Cartesian path");
        }
    }

private:
    void planAndExecute() {
        moveit::planning_interface::MoveGroupInterface::Plan plan;
        if (move_group_->plan(plan) != moveit::core::MoveItErrorCode::SUCCESS) {
            throw std::runtime_error("Planning failed");
        }
        if (move_group_->execute(plan) != moveit::core::MoveItErrorCode::SUCCESS) {
            throw std::runtime_error("Execution failed");
        }
    }

    std::shared_ptr<moveit::planning_interface::MoveGroupInterface> move_group_;
};

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    auto node = std::make_shared<MoveIt2Controller>();
    node->init();
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}

双臂联动 ​

both_arms 支持位姿目标、关节角目标、命名姿态：

cpp
// node 必须已经由 std::shared_ptr 托管，不能在 node 的构造函数中创建 dual。
auto dual = std::make_shared<moveit::planning_interface::MoveGroupInterface>(
    node, "both_arms");
dual->setPlanningTime(5.0);
dual->setMaxVelocityScalingFactor(0.05);
dual->setMaxAccelerationScalingFactor(0.05);

auto plan_and_execute = [&dual]() {
    moveit::planning_interface::MoveGroupInterface::Plan plan;
    if (dual->plan(plan) != moveit::core::MoveItErrorCode::SUCCESS) {
        throw std::runtime_error("Dual-arm planning failed");
    }
    if (dual->execute(plan) != moveit::core::MoveItErrorCode::SUCCESS) {
        throw std::runtime_error("Dual-arm execution failed");
    }
};

// 1. 位姿目标：左右 tip 各设置一次
if (!dual->setPoseTarget(left_target_pose, "left_link7") ||
    !dual->setPoseTarget(right_target_pose, "right_link7")) {
    throw std::runtime_error("Invalid dual-arm pose target");
}
plan_and_execute();

// 2. 关节角目标：从运行时接口读取 vector 顺序，不要硬编码左右臂顺序。
const auto joint_names = dual->getJointNames();
auto joints = dual->getCurrentJointValues();
if (joint_names.size() != joints.size()) {
    throw std::runtime_error("Joint name/value size mismatch");
}
// 按名称找到要修改的关节；此处仅示意基于当前状态的小幅目标。
for (std::size_t i = 0; i < joint_names.size(); ++i) {
    if (joint_names[i] == "joint1-l") joints[i] += 0.02;
    if (joint_names[i] == "joint1-r") joints[i] -= 0.02;
}
dual->clearPoseTargets();
if (!dual->setJointValueTarget(joints)) {
    throw std::runtime_error("Invalid dual-arm joint target");
}
plan_and_execute();

// 3. 预置命名姿态
if (!dual->setNamedTarget("dual_ready")) {
    throw std::runtime_error("Unknown named target: dual_ready");
}
plan_and_execute();

底层 Action Client ​

cpp
#include <chrono>
#include <memory>
#include <stdexcept>
#include <string>
#include <vector>

#include <rclcpp/rclcpp.hpp>
#include <moveit_msgs/action/move_group.hpp>
#include <moveit_msgs/msg/constraints.hpp>
#include <moveit_msgs/msg/joint_constraint.hpp>
#include <moveit_msgs/msg/move_it_error_codes.hpp>
#include <rclcpp_action/rclcpp_action.hpp>

class MoveIt2ActionClient : public rclcpp::Node {
public:
    using MoveGroup = moveit_msgs::action::MoveGroup;
    using GoalHandle = rclcpp_action::ClientGoalHandle<MoveGroup>;

    MoveIt2ActionClient() : Node("moveit2_action_client") {}

    // 必须在 std::make_shared<MoveIt2ActionClient>() 完成后调用。
    void init() {
        action_client_ = rclcpp_action::create_client<MoveGroup>(
            shared_from_this(), "/move_action");
    }

    void sendJointGoal(const std::string& group_name,
                       const std::vector<std::string>& joint_names,
                       const std::vector<double>& positions) {
        if (joint_names.size() != positions.size() || joint_names.empty()) {
            throw std::invalid_argument("Joint name/value size mismatch");
        }
        if (!action_client_->wait_for_action_server(std::chrono::seconds(10))) {
            throw std::runtime_error("/move_action is not available");
        }

        MoveGroup::Goal goal;
        goal.request.group_name = group_name;
        goal.request.num_planning_attempts = 1;
        goal.request.allowed_planning_time = 5.0;
        goal.request.max_velocity_scaling_factor = 0.05;
        goal.request.max_acceleration_scaling_factor = 0.05;
        goal.request.start_state.is_diff = true;

        moveit_msgs::msg::Constraints constraints;
        for (std::size_t i = 0; i < joint_names.size(); ++i) {
            moveit_msgs::msg::JointConstraint joint;
            joint.joint_name = joint_names[i];
            joint.position = positions[i];
            joint.tolerance_above = 0.01;
            joint.tolerance_below = 0.01;
            joint.weight = 1.0;
            constraints.joint_constraints.push_back(joint);
        }
        goal.request.goal_constraints.push_back(constraints);
        goal.planning_options.planning_scene_diff.is_diff = true;
        goal.planning_options.plan_only = false;

        auto send_options = rclcpp_action::Client<MoveGroup>::SendGoalOptions();
        send_options.goal_response_callback = [this](const GoalHandle::SharedPtr& handle) {
            if (!handle) {
                RCLCPP_ERROR(get_logger(), "Goal was rejected");
            }
        };
        send_options.feedback_callback = [this](
            GoalHandle::SharedPtr,
            const std::shared_ptr<const MoveGroup::Feedback> feedback) {
            RCLCPP_INFO(get_logger(), "State: %s", feedback->state.c_str());
        };
        send_options.result_callback = [this](const GoalHandle::WrappedResult& wrapped) {
            const bool success =
                wrapped.code == rclcpp_action::ResultCode::SUCCEEDED &&
                wrapped.result &&
                wrapped.result->error_code.val ==
                    moveit_msgs::msg::MoveItErrorCodes::SUCCESS;
            if (success) {
                RCLCPP_INFO(get_logger(), "Goal succeeded");
            } else {
                const int error_code = wrapped.result ? wrapped.result->error_code.val : 0;
                RCLCPP_ERROR(get_logger(), "Goal failed, MoveIt error code: %d", error_code);
            }
        };

        action_client_->async_send_goal(goal, send_options);
    }

private:
    rclcpp_action::Client<MoveGroup>::SharedPtr action_client_;
};

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    auto node = std::make_shared<MoveIt2ActionClient>();
    node->init();
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}

Python 示例 ​

Python 端可直接通过 rclpy 的 Action Client 与 /move_action 通信。以下程序默认仅规划；确认目标来自最新真实状态并审查规划轨迹后，才应把 plan_only 改为 False。

python
import rclpy
from action_msgs.msg import GoalStatus
from moveit_msgs.action import MoveGroup
from moveit_msgs.msg import Constraints, JointConstraint, MotionPlanRequest, PlanningOptions
from moveit_msgs.msg import MoveItErrorCodes
from rclpy.action import ActionClient
from rclpy.node import Node


class MoveIt2Client(Node):
    def __init__(self):
        super().__init__("moveit2_client")
        self._client = ActionClient(self, MoveGroup, "/move_action")

    def send_joint_goal(
        self, group_name: str, joint_names: list[str], positions: list[float],
        plan_only: bool = True,
    ):
        """关节空间目标。"""
        if not joint_names or len(joint_names) != len(positions):
            raise ValueError("joint_names and positions must have the same non-zero length")
        if not self._client.wait_for_server(timeout_sec=10.0):
            raise RuntimeError("/move_action is not available")

        goal = MoveGroup.Goal()
        req = MotionPlanRequest()
        req.group_name = group_name
        req.num_planning_attempts = 1
        req.allowed_planning_time = 5.0
        req.max_velocity_scaling_factor = 0.05
        req.max_acceleration_scaling_factor = 0.05
        req.start_state.is_diff = True

        constraints = Constraints()
        for name, position in zip(joint_names, positions):
            jc = JointConstraint()
            jc.joint_name = name
            jc.position = position
            jc.tolerance_above = 0.01
            jc.tolerance_below = 0.01
            jc.weight = 1.0
            constraints.joint_constraints.append(jc)
        req.goal_constraints.append(constraints)

        goal.request = req
        goal.planning_options = PlanningOptions()
        goal.planning_options.planning_scene_diff.is_diff = True
        goal.planning_options.plan_only = plan_only

        send_future = self._client.send_goal_async(
            goal, feedback_callback=self._on_feedback,
        )
        rclpy.spin_until_future_complete(self, send_future, timeout_sec=10.0)
        if not send_future.done():
            raise TimeoutError("Timed out waiting for goal response")

        handle = send_future.result()
        if handle is None or not handle.accepted:
            raise RuntimeError("Goal was rejected")

        result_future = handle.get_result_async()
        rclpy.spin_until_future_complete(self, result_future, timeout_sec=60.0)
        if not result_future.done():
            raise TimeoutError("Timed out waiting for MoveIt result")

        wrapped = result_future.result()
        if (
            wrapped.status != GoalStatus.STATUS_SUCCEEDED
            or wrapped.result.error_code.val != MoveItErrorCodes.SUCCESS
        ):
            raise RuntimeError(
                f"MoveIt failed: status={wrapped.status}, "
                f"error_code={wrapped.result.error_code.val}"
            )
        return wrapped.result

    def _on_feedback(self, feedback):
        self.get_logger().info(f"state: {feedback.feedback.state}")


def main():
    rclpy.init()
    node = MoveIt2Client()
    try:
        node.send_joint_goal(
            "left_arm",

        node.destroy_node()
        rclpy.shutdown()

速度缩放与限位 ​

当前发布的 MoveIt 配置中，关节级最大速度上限约 3.14 rad/s（180°/s），最大加速度上限约 5.0 rad/s²。它们是规划模型使用的配置上限，不是硬件性能认证值。max_velocity_scaling_factor 和 max_acceleration_scaling_factor 在这些配置上限的基础上缩放，不能独立保证运动安全或实际跟踪精度。

场景max_velocity_scaling_factormax_acceleration_scaling_factor
首次低速验证0.050.05
已完成风险评估后的低速验证最高 0.1最高 0.1

⚠️ 注意：首次使用应从 0.05 开始。高于 0.1 的真机范围未在本文档验证中认证，不能仅根据配置上限直接使用。

当前桥接配置中的 0.10 rad 是 FollowJointTrajectory 的关节终点到位阈值，不是应用保证的定位精度。Action 成功只表示执行链路按该阈值完成；需要更严格精度的应用还应读取完整、新鲜、有限值的真实关节反馈，并按自己的误差门槛再次判定。
