安装 ROS 2 Jazzy ​

H1 使用 ROS 2 Jazzy，通信中间件为 Cyclone DDS（rmw_cyclonedds_cpp）。开发电脑安装 ROS 2 后，还需要将 RMW 切换为 Cyclone DDS，才能发现机器人并收发话题。

如何选择

ROS 2 Jazzy 官方提供 Ubuntu、Windows 和 macOS 的安装或构建说明，这些平台都可以用于 H1 SDK 开发。我们优先推荐 Ubuntu 24.04 LTS（amd64 或 arm64）：它有官方 deb 包，安装和后续升级都更方便。Windows 和 macOS 用户也可以选择原生安装、Docker；Windows 还可以使用 WSL2。

运行环境安装方式接入 H1 时需要注意
Ubuntu 24.04官方 deb 包或源码构建推荐，安装最简单
Windows 10 amd64官方二进制包或源码构建启用 Cyclone DDS，并放行可信网络上的 DDS 通信
macOS按官方文档从源码构建确认构建结果包含 Cyclone DDS RMW
Docker使用 ROS 官方镜像配置容器网络，使 DDS 能发现机器人
WSL2在 Windows 中安装 Ubuntu 24.04确认 WSL2 与机器人之间网络互通

完成对应平台的安装后，再按 H1 Cyclone DDS 配置与通信检查连接机器人。

Ubuntu 24.04（推荐） ​

ROS 2 Jazzy 的官方 deb 包适用于 Ubuntu Noble 24.04。下面的命令按 Ubuntu 24.04 编写，不适用于 Ubuntu 22.04 或其他发行版。

1. 配置 UTF-8 与软件源 ​

bash
sudo apt update
sudo apt install -y locales software-properties-common curl
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

sudo add-apt-repository universe

export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest \
  | grep -F 'tag_name' | awk -F'"' '{print $4}')
curl -L -o /tmp/ros2-apt-source.deb \
  "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"
sudo dpkg -i /tmp/ros2-apt-source.deb

Windows 10 amd64 ​

ROS 2 Jazzy 为 Windows 10 amd64 提供官方二进制包，也可以从源码构建。连接 H1 前，请确认安装中包含 rmw_cyclonedds_cpp，并允许 ROS 2/DDS 通过 Windows 防火墙访问当前可信网络。

1. 准备 pixi 环境 ​

在 PowerShell 中执行：

powershell
mkdir C:\pixi_ws
cd C:\pixi_ws

# 先按 https://pixi.sh/latest/ 安装 pixi，然后重新打开 PowerShell
Invoke-WebRequest -Uri https://raw.githubusercontent.com/ros2/ros2/refs/heads/jazzy/pixi.toml -OutFile pixi.toml
pixi install

2. 下载 ROS 2 Jazzy 二进制包 ​

从 ROS 2 Releases 下载 Jazzy 的 Windows amd64 压缩包，文件名类似：

text
ros2-jazzy-*-windows-release-amd64.zip
1

将其解压到固定目录：

text
C:\pixi_ws\ros2-windows
1

Windows 二进制包目前不可重定位，解压后请保留这个目录。

3. 加载环境并检查 Cyclone DDS ​

每次新开 cmd.exe 后执行：

bat
cd C:\pixi_ws
pixi shell
call C:\pixi_ws\ros2-windows\local_setup.bat

ros2 --help
ros2 pkg prefix rmw_cyclonedds_cpp
set RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
echo %RMW_IMPLEMENTATION%

如果 ros2 pkg prefix rmw_cyclonedds_cpp 提示找不到包，需要按照 ROS 2 官方源码构建说明补充 Cyclone DDS，或改用本页列出的其他安装方式。不要在未验证的情况下切回 Fast DDS，因为机器人端使用的是 Cyclone DDS。

首次运行 ROS 2 程序时，Windows 可能弹出防火墙提示。请只为可信网络放行，并确保电脑和机器人接入同一网络。如果看不到 /device_info，再检查防火墙、多网卡和路由设置。

macOS ​

ROS 2 Jazzy 提供官方的 macOS 源码构建说明。构建前需要准备 Xcode、Homebrew 和 Python 依赖，完整依赖及版本要求请以 ROS 2 官方文档为准。除了原生构建，也可以在 macOS 上使用 Docker 或 Ubuntu 24.04 虚拟机。

方式一：原生 macOS 源码构建 ​

先完整执行 ROS 2 官方 macOS 页面中的 Xcode、Homebrew、Python 和系统依赖步骤，再获取 Jazzy 源码并构建：

bash
mkdir -p ~/ros2_jazzy/src
cd ~/ros2_jazzy
vcs import --input https://raw.githubusercontent.com/ros2/ros2/jazzy/ros2.repos src
colcon build --symlink-install --packages-skip-by-dep python_qt_binding
1
2
3
4

构建完成后，在新终端加载并确认 Cyclone DDS RMW 可用：

bash
source ~/ros2_jazzy/install/setup.zsh
ros2 pkg prefix rmw_cyclonedds_cpp
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
1
2
3

如果找不到 rmw_cyclonedds_cpp，请按照官方源码构建说明补充 Cyclone DDS 支持。这一步只是确认构建结果满足 H1 的通信要求。

方式二：Docker 或 Ubuntu 虚拟机 ​

macOS 也可以运行 ROS 2 Jazzy Docker 容器，或在 Ubuntu 24.04 虚拟机中按照前文步骤安装。无论使用容器还是虚拟机，都需要确保 DDS 发现和话题数据能够到达机器人；虚拟机通常需要使用桥接网络。

官方说明：macOS source build。

Docker ​

ROS 官方提供 Jazzy Docker 镜像，可在 Linux、Windows Docker Desktop 和 macOS Docker Desktop 上运行。下面以精简的 ros:jazzy-ros-base 为例：

bash
docker pull ros:jazzy-ros-base
docker run --rm -it ros:jazzy-ros-base bash
1
2

进入容器后安装并选择 Cyclone DDS：

bash
apt update
apt install -y ros-jazzy-rmw-cyclonedds-cpp
source /opt/ros/jazzy/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
ros2 pkg prefix rmw_cyclonedds_cpp
1

3
4

连接 H1 时，容器网络需要支持 DDS 发现和话题通信。Linux 可以根据实际环境使用 host 网络；Windows 和 macOS 上的 Docker Desktop 网络机制不同，不应直接照搬 Linux 参数。配置完成后，请在容器内订阅 /device_info 验证连接。

官方镜像：ROS Docker Official Image。

Windows WSL2 ​

Windows 用户也可以通过 WSL2 运行 Ubuntu 24.04，再按照前文的 Ubuntu 步骤安装 ROS 2 Jazzy 和 Cyclone DDS：

powershell
# Windows PowerShell（管理员）
wsl --install -d Ubuntu-24.04
1
2

安装完成后，还需要确认 WSL2 能通过 DDS 发现机器人。NAT、Windows 防火墙、多网卡、VPN 或禁用组播的网络都可能影响发现。请在 WSL2 中执行：

bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
ros2 daemon stop
ros2 daemon start
ros2 topic list
ros2 topic echo /device_info --once
1
2
3
4
5

WSL2 内的 talker/listener 能正常通信，只能说明本机 ROS 2 环境可用；能够收到机器人的 /device_info，才说明跨机 DDS 已连接。

安装后的 H1 通信检查 ​

无论选择哪种运行环境，都请先确认本机 ROS 2 可用，再检查与机器人的通信：

bash
# Linux/macOS；Windows cmd.exe 使用 set RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
ros2 daemon stop
ros2 daemon start
ros2 topic list
ros2 topic echo /device_info --once

确认能够收到 /device_info，并检查 /diagnostics 中的 overall.task_allowed=true 后，再运行运动控制示例。机器人端服务的检查方法见机内服务与重启。
