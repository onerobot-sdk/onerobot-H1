ROS 2 通信配置 ​

H1 标准版与智能版共用 ROS 2 Jazzy + 原生 Zenoh（rmw_zenoh_cpp） 开发环境。建议先更新机器人固件，再按本页配置开发电脑。

开始前：查看固件版本 ​

  1. 在电脑浏览器打开网络配置工具：http://<机器人IP>:8080。网线直连时为 http://10.42.0.2:8080。
  2. 进入 「状态」→「机器人信息」，查看 「软件版本」。

建议使用最新固件

当前推荐固件为 1.0.104.261028。如果设备使用的是旧版本，建议先升级到最新适配固件，再按下方 Zenoh 步骤配置电脑。

查看固件版本与查询说明，升级方法见网络配置与 OTA。升级完成后，电脑也需要加载本页的通信环境。

暂时无法升级的标准版设备，可使用页末的兼容说明。

连接机器人 ​

先让开发电脑能够访问机器人。网线直连时使用 H1 对外地址 10.42.0.2；电脑网口设置见 FAQ：网线直连。连接机器人热点时使用 192.168.60.1；同一局域网中使用机器人的实际 IP。

下文 H1_IP 均填写 H1 的对外地址。智能版内部 NVIDIA 计算板的地址用于板端登录；双板连接及登录方法见智能版：连接与使用。

开发电脑的 Zenoh 环境 ​

本节适用于 Ubuntu 24.04 / ROS 2 Jazzy，所有安装、文件配置和 systemd 命令均在开发电脑上执行。 机器人和 NVIDIA 计算板沿用固件交付的通信环境。

电脑上的 ROS 2 节点通过本地 Zenoh router 连接 H1 的 Zenoh router，目标端口为 TCP 7447。仅设置 RMW_IMPLEMENTATION 还不够，需要完成下面的 router 配置。

1. 安装软件包 ​

开发电脑需要 Ubuntu 24.04 和 ROS 2 Jazzy。尚未安装 ROS 2 时，先按 安装 ROS 2 Jazzy配置软件源并安装 ROS 2，再继续本节。

沿用已配置的 ROS 软件源安装 Zenoh：

bash
sudo apt update
sudo apt install -y ros-jazzy-rmw-zenoh-cpp ros-jazzy-zenoh-cpp-vendor

source /opt/ros/jazzy/setup.bash
ros2 pkg prefix rmw_zenoh_cpp
dpkg-query -W ros-jazzy-rmw-zenoh-cpp

2. 配置电脑的 router ​

下面以网线直连为例。接入路由器时，先将 H1_IP 改成 H1 在局域网内的实际地址：

bash
H1_IP=10.42.0.2
sudo install -d -m 755 /etc/zenoh
sudo tee /etc/zenoh/router.env > /dev/null <<EOF
ZENOH_CONFIG_OVERRIDE='listen/endpoints=["tcp/127.0.0.1:7447"];connect/endpoints=["tcp/${H1_IP}:7447"];routing/router/peers_failover_brokering=true;transport/link/tx/queue/congestion_control/drop/wait_before_drop=1000000'
EOF

listen/endpoints 是电脑本地监听地址，connect/endpoints 是机器人地址。更换连接方式或 H1 的 IP 后，修改 /etc/zenoh/router.env 中的 connect/endpoints，然后重启电脑的 zenoh-router.service。

创建电脑的服务文件：

bash
sudo tee /etc/systemd/system/zenoh-router.service > /dev/null <<'EOF'
[Unit]
Description=H1 development PC Zenoh router
After=network.target
StartLimitIntervalSec=0

[Service]
Type=exec
Environment=ZENOH_ROUTER_CONFIG_URI=/opt/ros/jazzy/share/rmw_zenoh_cpp/config/DEFAULT_RMW_ZENOH_ROUTER_CONFIG.json5
Environment=RUST_LOG=zenoh=info
EnvironmentFile=/etc/zenoh/router.env
UnsetEnvironment=CYCLONEDDS_URI
ExecStart=/bin/bash -ec 'source /opt/ros/jazzy/setup.bash; exec /opt/ros/jazzy/lib/rmw_zenoh_cpp/rmw_zenohd'
Restart=on-failure
RestartSec=2s
TimeoutStopSec=5s

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable zenoh-router.service
sudo systemctl restart zenoh-router.service
systemctl status zenoh-router.service --no-pager

3. 在开发终端加载环境 ​

将 Zenoh 环境保存为独立文件，后续打开终端时直接加载即可。若 ~/.bashrc 等 Shell 启动文件中已有旧的 RMW_IMPLEMENTATION=rmw_cyclonedds_cpp，请同步整理，避免后续加载时覆盖本节设置。

bash
cat > ~/h1-zenoh-env.sh <<'EOF'
source /opt/ros/jazzy/setup.bash
unset CYCLONEDDS_URI ZENOH_SESSION_CONFIG_URI ZENOH_CONFIG_OVERRIDE
export RMW_IMPLEMENTATION=rmw_zenoh_cpp
export ROS_DOMAIN_ID=0
export ZENOH_SESSION_CONFIG_URI=/opt/ros/jazzy/share/rmw_zenoh_cpp/config/DEFAULT_RMW_ZENOH_SESSION_CONFIG.json5
export ZENOH_CONFIG_OVERRIDE='transport/link/tx/queue/congestion_control/drop/wait_before_drop=1000000'
EOF

source ~/h1-zenoh-env.sh
echo "$RMW_IMPLEMENTATION"
echo "$ROS_DOMAIN_ID"

输出应分别为 rmw_zenoh_cpp 和 0。每个运行 H1 ROS 2 命令的电脑 Bash 终端都需要加载一次 source ~/h1-zenoh-env.sh；使用其他 Shell 时，可以先运行 bash 进入 Bash。

机器人未单独设置 ROS_DOMAIN_ID 时使用默认域 0；电脑显式设置为 0，避免沿用其他项目的域 ID。设备若有定制域配置，电脑应与设备一致。尚未升级的标准版设备见页末兼容说明。

本节使用的配置文件与环境变量可参阅 rmw_zenoh 官方配置说明。

验证通信与排查 ​

执行位置：已完成上述配置的开发电脑终端。 如果之前使用过其他 RMW，先停止旧的 ROS 2 CLI daemon，再检查话题与实际消息：

bash
source ~/h1-zenoh-env.sh
ros2 daemon stop
ros2 topic list
ros2 topic echo /device_info --once
1
2
3
4

收到机器人发布的 /device_info 消息，才表示电脑已接收到机器人数据。也可以通过 ros2 topic echo /scan --once 检查雷达消息；雷达服务需正常运行。仅能 ping、SSH 登录或看到话题列表，不等于对应话题有数据。

现象检查方法
升级后 SSH 正常，但没有机器人话题确认已配置电脑 router，并在当前终端加载 ~/h1-zenoh-env.sh；不要继续使用旧的 Cyclone DDS 环境
电脑没有机器人话题核对 RMW_IMPLEMENTATION、域 ID、router 目标 IP、TCP 7447 连通性及 router 日志
电脑 router 无法启动查看服务日志，核对配置路径、安装包版本及 7447 端口是否已有其他 router 占用
切换机器人或网络后无法通信将电脑 /etc/zenoh/router.env 中的目标 IP 改为当前 H1 地址，再重启电脑 router
有话题但没有消息核对机器人对应功能服务、话题发布状态及通信链路

电脑 router 的只读检查命令：

bash
systemctl status zenoh-router.service --no-pager -l
journalctl -u zenoh-router.service -b -n 100 --no-pager
1
2

机器人端服务的状态查询见机内服务与重启。智能版还可在 NVIDIA 计算板上验证通信。运行运动控制示例前，按对应示例核对设备状态与前置条件。

尚未升级的标准版：Cyclone DDS 配置

本节仅适用于 早于 1.0.104.261028 的标准版固件。早期智能版已使用 Zenoh，不适用本节。

在 Ubuntu 24.04 开发电脑上安装并加载 Cyclone DDS：

bash
sudo apt update
sudo apt install -y ros-jazzy-rmw-cyclonedds-cpp
source /opt/ros/jazzy/setup.bash
unset ZENOH_SESSION_CONFIG_URI ZENOH_CONFIG_OVERRIDE
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
ros2 pkg prefix rmw_cyclonedds_cpp
echo "$RMW_IMPLEMENTATION"
