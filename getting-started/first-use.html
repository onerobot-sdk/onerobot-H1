H1 开箱与首次使用 ​

首次收到机器人时，按 开箱检查 → 开机前准备 → 开机 → 手柄操作 → 关机 的顺序完成基础使用。本文适用于 H1 标准版和智能版，配件及选配功能以收到的实物为准。

要做什么说明位置
检查机器人与配件开箱检查、开机前准备
找到电源开关、查看灯效开机、状态指示灯
连接手柄、查询按键功能手柄准备、按键功能
结束使用或处理紧急情况正常关机、紧急停止
联网、调试与开发下一步

开箱检查 ​

  1. 清点物品。 按随箱装箱单核对机器人、手柄及其他配件，检查包装、外壳、机械臂、已配置的末端执行器和线缆有无损伤。
  2. 协作搬运。 整机重量约 77 kg，由足够人员配合搬运。禁止拖拽机械臂、头部、线缆或传感器。
  3. 检查安装状态。 确认机器人、已配置的支架及工作站放置稳定，底盘、紧固件没有松动、变形或运输移位。

发现松动、破损、漏液、异味或异常发热时，停止使用并联系技术支持。

开机前准备 ​

首次上电应由接受过培训的人员完成。每次使用前，逐项确认以下内容。

检查项需要确认的内容
工作区运动范围已清空，隔离和监护措施已就绪，操作员站在安全位置
机器人外观双臂、头部、升降机构、底盘及已安装夹爪无损伤
初始姿态机械臂及已配置的主臂处于交付要求的初始位置
电源与线缆电池电量满足任务要求，电源及通信连接牢固
周边空间关节、底盘和线缆周围无异物、缠绕或干涉
急停已了解按钮位置、使用方式，急停功能检查正常
操作人员已束起长发，衣物和随身物品远离运动区域，能够集中注意力操作

如配置主从系统，按交付要求连接网线及控制线缆，锁紧接口。外部算力工作站和遥操作主机按配套说明上电，确认主臂处于初始位置。

开机 ​

找到电源开关 ​

H1 的机身普通开关、应急开关和遥控开关如下图。遥控开关是否配置，以收到的实物为准。 点击图片可查看原图。

开关操作方式
机身普通开关点按后按键凹入为通电，按键弹起为断电
遥控开关（选配）点按 ON 通电，点按 OFF 断电
应急开关（急停）顺时针旋转解除急停，直接按下触发急停，可隔着红胶套按下

上电步骤 ​

  1. 完成开机前准备，确认机器人运动范围内无人。
  2. 确认应急开关已解除，并检查机身普通开关。按键处于凹入状态表示通电；若按键弹起，点按至凹入状态。如配有遥控开关，点按 ON，让已配置的电源开关均处于通电状态。
  3. 等待机器人完成启动和初始化，再连接手柄或进入网页工具检查状态。

初始化期间

初始化和校准期间，机械臂可能发生运动。人员应远离机械臂可达范围，保持双手离开关节。

状态指示灯 ​

灯效含义
白灯慢闪未联网
白灯常亮正常
红灯常亮故障
红灯慢闪低电
白灯呼吸充电

白灯慢闪时，可按网络配置与 OTA连接机器人。红灯常亮时，先通过 H1 调试工具检查状态并处理故障，再进行运动操作。

手柄准备 ​

外观与连接 ​

下图为本说明书中的手柄。连接机器人前，将手柄背面下方的拨动开关拨到最左侧。 点击图片可查看开关位置和放大图。

  1. 机器人完成开机后，将手柄放在机器人附近，核对背面拨动开关位置。
  2. 按 Play（HOME） 键打开手柄。
  3. 如需重新配对，按手柄配对说明选择所配手柄对应的操作方式。

手柄右上方为 Y、B、A、X 按钮，左下方为十字方向键。中间有 Start、Back、Fn（TURBO）、Play（HOME），顶部有 LB、LT、RB、RT，左右各有一个摇杆。

旧款手柄外观参考

旧款手柄的重新配对组合键见配对说明。

按键功能 ​

按键功能
Play（HOME）手柄开机
Start进入主臂控制从臂模式 / 重置姿态，主从控制需配套遥操作设备
Back退出当前模式，进入待机状态，配套固件会执行归位、升降及头部校准
Y / A身体上升 / 下降
按住 LB左夹爪张开，松开后恢复夹紧
按住 RB右夹爪张开，松开后恢复夹紧
按一下 LT / RT加速 / 减速
十字方向键 上 / 下底盘前进 / 后退
十字方向键 左 / 右底盘原地逆时针 / 顺时针旋转
右摇杆上、下、左、右控制头部对应转动

LT / RT 按当前控制对象调节速度，升降和底盘独立调节。 控制升降时调节升降速度，控制底盘时调节底盘速度。

首次操作与注意事项 ​

  1. 确认运动范围内无人、无障碍物，先以低速、空载方式熟悉控制。移动底盘、升降或转动头部前，检查对应运动范围。
  2. 一次完成一个操作，等待当前动作完成后再切换。避免连续重复按同一按键，禁止使用未知功能的按键。
  3. Start / Back 会触发姿态调整、归位或校准，具体动作取决于配套固件和设备配置。操作前清空机械臂、升降及头部的运动范围，出现危险时使用本体物理急停。
  4. 操作夹爪时保持手和物品远离夹持区域，注意 LB / RB 松开后夹爪会恢复夹紧。
  5. 如使用主从遥操作系统，主臂、从臂、手柄和笔记本按交付配套使用。先低速分别检查左臂、右臂和夹爪，再进行双臂操作。映射方向或零位不确定时，退出遥操作并检查。

手柄没有反应或无法配对时，见手柄遥操作常见问题。

正常关机 ​

  1. 结束当前任务，将双臂和负载置于安全状态，退出控制或遥操作模式，确认机器人停止运动。
  2. 保存需要保留的数据，按配套说明关闭已配置的外部工作站和遥操作设备。
  3. 点按机身普通开关，使按键弹起断电。如使用配套遥控开关，点按 OFF 断电。

日常关机按上述顺序完成。避免拔掉电源或反复按压电源键，强制断电可能造成机械臂下落、硬件损坏或数据丢失。固件升级期间应保持供电稳定。

紧急停止 ​

  1. 出现失控、碰撞、夹挤、异常高速运动或人员进入危险区域时，立即按下本体应急开关（急停），可隔着红胶套按下。
  2. 保持人员远离设备，等待所有运动停止。失能后机械臂可能受重力影响下落，必要时由受训人员固定机械臂和负载。
  3. 查明原因并完成设备检查，确认运动范围内安全后，顺时针旋转解除急停。解除急停时机器人可能恢复供电，应按开机步骤核对各开关的当前状态，等待启动和初始化完成后再操作。

  • 网络配置与 OTA — 连接机器人、配置 WiFi、查看固件版本及升级。
  • H1 调试工具 — 检查设备状态，使用建图、定位、导航和回充等功能。
