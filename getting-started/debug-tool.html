H1 调试工具使用说明 ​

H1 调试工具是机器人自带的网页工具，端口为 8090。通过浏览器可以完成建图、定位、导航、硬件检查、相机预览及日志采集，用于设备调试和功能验证。

首次使用建议按 连接工具 → 检查状态 → 建图或加载地图 → 启动定位 → 导航 的顺序操作。升降与头部控制、系统诊断功能可按需要进入，具体功能以设备配置和已安装固件为准。

要做什么说明位置
打开网页、查看设备和接口状态连接与访问、状态检查
准备场景地图并定位机器人建图、地图管理、定位
记录目标点、导航和取消任务点位与导航
设置上桩方向、执行上桩并确认充电回充
检查与控制升降、头部升降与头部控制
查看相机、收集故障信息系统诊断、日志下载、ROS Bag 录制

下文截图用于对照页面和操作入口，设备状态、地图、点位及记录以实际机器人为准。点击截图可查看原图。

连接机器人并打开工具 ​

机器人开机后，让电脑与机器人连接到同一网络，使用 Chrome 或 Edge 打开对应地址：

接入方式访问地址
网线直连http://10.42.0.2:8090
机器人热点http://192.168.60.1:8090
同一局域网http://<机器人IP>:8090

网线直连时，先按电脑有线网络设置配置网卡，可直接查看 Ubuntu 或 Windows 的操作截图。电脑使用 10.42.0.1，机器人使用 10.42.0.2，不要设置成同一地址。

如果已经能打开网络配置工具，无需重复配置电脑 IP，将网页端口从 8080 改为 8090 即可。H1 调试工具无需另行登录。建议使用最新适配固件；较早固件可能没有下文中的部分功能。

使用前检查 ​

打开页面后，先检查顶部状态条和左侧栏底部的「软件版本」。软件版本是机器人已安装的整机固件版本，版本查询与升级说明见固件版本。

顶部各接口状态标记的含义如下：

颜色含义操作建议
绿色 ok接口当前正常按对应功能的前提继续操作
黄色 stale消息更新超时到「系统诊断 → 接口健康」查看具体接口
红色 response_timeout指令发出后等待响应超时先确认相关服务与设备状态，再进行依赖它的操作
灰色 never_seen尚未收到消息，或发布接口尚未发送结合接口方向及使用情况判断；灰色本身不代表故障

运动操作前

导航、回充及执行器操作会驱动机器人。开始前清空运动范围，确保无人、无障碍物，并保持物理急停可用。不要同时下发互相冲突的任务；出现异常时先停止操作。

建图、地图与定位 ​

建图 ​

  1. 将机器人放到建图起点，通常为充电桩位置。
  2. 进入「算法测试 → 建图」，点击 「开始建图」。当前流程使用充电桩起点，无需手填起始位姿。
  3. 使用遥控器控制机器人遍历场地，查看实时地图预览中的扫描区域。
  4. 扫描完成后点击 「完成建图」，等待地图保存与加载完成，再进行定位或导航。

建图期间，定位和导航会受互斥条件限制。需要进行下一项操作时，先完成建图。

地图管理 ​

已有配套场景地图时，可在 「算法测试 → 地图」 页导入地图包：

  1. 先结束建图、导航等正在运行的任务。需要保留当前地图时，先导出备份。
  2. 在「导入地图包」区域点击 「选择文件」，选择原始地图 ZIP，无需解压或重新打包。
  3. 点击 「导入地图」，确认替换当前地图。
  4. 页面提示「已下发地图导入」后，核对地图画面与元信息，再进入定位页确认定位结果。

「已下发」表示请求已发送，不等于地图已经生效。地图需要与实际场景匹配；洗衣场景的地图和布置要求见洗衣服场景示例。

启动定位 ​

  1. 确认地图已建好或已加载。
  2. 将机器人放回与地图对应的充电桩位置；页面的「启动定位」使用充电桩定位方式。
  3. 进入「算法测试 → 定位」，点击 「启动定位」。
  4. 等待状态变为 locating_success，再记录导航点位或下发导航任务。

定位未成功时，先检查地图、机器人位置及相关接口状态，不要继续下发导航。

点位与导航 ​

记录预设点位 ​

  1. 完成定位，将机器人开到目标位置与朝向。
  2. 在导航页确认定位状态为 locating_success。
  3. 点击 「记录当前点位为 P1 / P2 / P3 / P4」 中对应的按钮。
  4. 对其余目标点重复操作，核对点位与场景是否匹配。

录入后先核对点位坐标。重启或更换地图、场景后，重新检查各点位；缺失或不匹配时，重新录入后再导航。

下发导航目标 ​

进入「算法测试 → 导航」，确认定位成功后，选择一种方式下发：

  • 预设点位：在「导航到」区域点击 P1 / P2 / P3 / P4。灰色点位表示尚未录入，需先记录。
  • 自定义位姿：填写 x / y / yaw，其中 yaw 使用弧度；按需勾选 is_accurate_pose，点击 「下发自定义点位」。

下发后观察任务状态与机器人运动情况，等待任务完成，再进行下一项操作。

取消导航 ​

在导航页点击红色 「取消当前任务」 按钮，并确认机器人停止、任务状态已更新。需要立即处置异常且页面操作无效时，使用本体物理急停。

回充 ​

配有回充板的 H1 可通过「算法测试 → 回充」设置上桩方向，并在充电座前执行精对位和电极对接。

  1. 准备上桩。 先结束建图、导航等正在运行的任务，将机器人放到充电座前的对接预备点附近，确认机器人与充电座之间的通道畅通。
  2. 核对方向。 查看「回充方向配置」下的「当前配置」。默认是 前进上桩、后退下桩。若设备需要倒车对接，选择 倒车上桩、前进下桩，点击「保存配置」，再核对「当前配置」。已有导航或上桩任务时，等任务结束，或取消任务并确认机器人停止后再改方向。
  3. 执行上桩。 在「上桩动作」中点击 「执行上桩（精对位与电极对接）」。页面提示「已下发上桩」后，查看本次任务的 task_id、目标「上桩对接」和状态。需要中止时，点击 「取消当前任务」，确认机器人已停止。
  4. 确认结果。 任务状态为 success 时，再查看左侧栏是否显示「在桩」和「充电中」，分别确认机器人已就位、已开始充电。若状态为 fail，查看「失败原因」。若侧栏显示「没有获取在桩和充电数据」，则暂时无法通过网页确认充电状态。

升降与头部控制 ​

进入 「硬件测试 → 执行器」，先查看状态，再按需要操作：

检查项说明
限位开关升降顶 / 底、头部俯仰到顶 / 到底、头部左 / 右，共 6 路；绿色表示未触发，黄色表示已触发限位，灰色表示无数据
电机告警查看头部堵转状态、升降报警码与说明
校准与手动微调按页面对应控件操作，动作前确认上方及头部运动范围无遮挡

出现堵转或升降报警时，先停止操作、排除机械卡阻，再按页面提示处理。需要清除升降报警时，在「校准」区域点击 「清除升降报警」，并重新核对状态。

系统诊断与数据采集 ​

接口健康 ​

进入 「系统诊断 → 接口健康」，查看各话题的状态、所属组、更新时间和异常详情。需要技术支持时，点击 「复制诊断信息」，将结果连同固件版本、操作步骤和异常时间提供给支持人员。

相机预览 ​

进入 「系统诊断 → 摄像头」，查看已安装相机的图像。头部、左 / 右相机及选配深度相机是否显示，以设备配置为准；未安装的选配相机没有图像不代表故障。

打开预览时会建立图像订阅，关闭后释放。图像传输会占用网络带宽和处理资源，帧率取决于相机与网络条件。相机话题和 QoS 见传感器。

下载机器人日志 ​

  1. 进入「系统诊断 → 接口健康」，点击 「打包下载日志」。
  2. 等待打包和下载完成；日志较大时进度可能暂时停顿。
  3. 保存下载的 ZIP，文件名通常包含设备 ID、固件版本和时间；提供给技术支持时附上对应操作和异常时间。

录制 ROS Bag ​

  1. 进入 「系统诊断 → ROS Bag」，按排查需要勾选话题。相机、点云等大流量话题按需选择。
  2. 点击 「开始录制」，完成需要记录的操作。
  3. 点击 「停止录制」，等待写入完成。
  4. 在列表中下载 tar 记录包，解压后可使用 ros2 bag play 回放。

同一时刻只允许一个录制任务；开始手动录制前，须先关闭自动录制。停止时不要断电。手动录制时，剩余磁盘空间低于 2 GiB 会自动停止，且无法开始新的手动录制。自动录制采用分段回收，按配额清理旧分段；仅在排查需要时开启，用完及时关闭。

在下方「录制状态」检查当前任务和磁盘剩余；「已录制的 Bag」列出可下载的记录。下载并确认所需数据已保存后，及时清理机器人上的录制文件，避免占满磁盘。

遇到问题 ​

访问失败、状态异常、定位不成功、相机无图或日志下载问题，见 H1 调试工具常见问题。需要查后台服务或重启命令时，见机内服务与重启。
