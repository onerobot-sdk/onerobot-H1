网络配置与 OTA 使用说明 ​

网络配置工具是机器人自带的网页，端口为 8080。通过它可以连接 WiFi、查看设备与固件版本、设置机器人标识，以及升级整机和配套硬件固件。

本页适用于 H1 标准版和智能版，具体功能以设备配置为准。首次使用建议先完成连接与访问，再查看状态与版本。日常联网见 WiFi 连接；升级时按下表选择对应页面。

要做什么说明位置
查看机器人热点、管理 WiFi热点信息、连接 WiFi、已保存网络与断开连接
设置机器人标识、查看 ROS 2 通信配置机器人配置
升级整机软件OTA 升级
升级机械臂电机、自研夹爪或回充板硬件固件升级
查看升级进度与结果升级状态与监控

当前推荐使用最新整机固件。网络配置工具的最低支持版本为 1.0.017.260509；较早固件可能没有下文中的部分功能，建议先升级。界面中的设备信息、网络名称和文件名以你的机器人为准。点击截图可查看原图。

连接机器人并打开工具 ​

机器人开机后，将电脑或手机与机器人连接到同一网络，再在浏览器打开对应地址。三种方式任选一种：

接入方式地址场景
网线直连http://10.42.0.2:8080开发 / 调试，先按下方说明配置电脑网卡
机器人热点http://192.168.60.1:8080手机 / 笔记本连接机器人热点后访问
同一局域网http://<机器人IP>:8080电脑与机器人连接同一局域网，机器人 IP 见「状态」页 WiFi 卡片

网线直连：先配置电脑的有线网络 ​

用网线连接电脑与机器人，确认机器人已开机、有线连接已接通，再按电脑系统完成以下设置。这里修改的是电脑上连接机器人的有线网卡：电脑使用 10.42.0.1，机器人使用 10.42.0.2，不要把电脑也设置成 10.42.0.2。

Ubuntu ​

按下图中的 1～5 顺序操作：

  1. 打开「设置」→「网络」。
  2. 在连接机器人的「有线」连接右侧，点击齿轮按钮。
  3. 切换到「IPv4」页签。
  4. 将「IPv4 方式」设为 「与其他计算机共享」。
  5. 点击「应用」，再关闭并重新打开该有线连接，使设置生效。

重新连接后，在该有线连接的「详细信息」中核对 IPv4 地址。访问 10.42.0.2 时，电脑应位于 10.42.0.0/24 网段，例如 10.42.0.1、子网掩码 255.255.255.0。若共享模式分配到了其他网段，可改选「手动」，填写上述地址和掩码，网关、DNS 留空，再应用并重新连接，用于直连访问机器人页面。

Windows ​

  1. 按 Win + R，输入 ncpa.cpl 并回车，打开「网络连接」。也可以从「控制面板」→「网络和 Internet」→「网络和共享中心」→「更改适配器设置」进入。
  2. 找到连接机器人的以太网网卡，右键选择「属性」。选择实际插着网线的物理网卡，不要选择 WLAN 或 VPN 虚拟网卡；名称可能与截图不同。

  1. 选中「Internet 协议版本 4（TCP/IPv4）」→「属性」，选择「使用下面的 IP 地址」，填写：
设置项填写内容
IP 地址（电脑）10.42.0.1
子网掩码255.255.255.0
默认网关留空
首选 / 备用 DNS 服务器留空（通过 IP 地址访问机器人页面无需 DNS）
  1. 点击 IPv4 属性窗口的「确定」，再点击以太网属性窗口的「确定」，保存设置。

以上设置用于网线直连。使用机器人热点或同一局域网接入时，按对应方式连接网络即可；有线网卡之后改接普通路由器时，恢复原来的网络设置（通常为自动获取 IP / DNS）。

配置完成后，在电脑浏览器打开 http://10.42.0.2:8080，进入网络配置工具。

状态页：查看连接、设备与版本 ​

打开工具后进入「状态」页，左侧菜单可切换其他功能。

  • WiFi 连接：查看当前网络名称、连接状态和机器人在该网络中的 IP 地址。
  • 机器人热点：查看热点名称、地址、运行状态与加密方式。
  • 电池：查看机器人上报的电池状态；出现「未订阅」时，表示当前未收到对应状态数据。

在「状态」页向下找到 「机器人信息」→「软件版本」，即可核对已安装的整机固件。这里还显示设备 ID、机器人 ID、型号和出厂序列号。

下方的机械臂电机、回充板软件版本属于对应硬件的固件版本，与整机软件版本分别管理。智能版在具备相应配置时还会显示 NVIDIA 计算板状态；未配置该功能的设备不显示此卡片。

版本查询与升级指引见固件版本。

连接 WiFi ​

  1. 进入左侧「WiFi 配置」页，查看「可用 WiFi」列表；未找到目标网络时，点击「刷新」重新扫描。
  2. 找到目标网络，点击右侧「连接」。
  3. 在弹出的连接窗口输入该网络的密码，再点击「连接」；开放网络按提示确认即可。
  4. 出现 已成功连接到 <SSID> 后，返回「状态」页核对网络名称和 IP 地址。

隐藏或扫描不到的网络，可点击 「手动连接」，填写准确的 WiFi 名称（SSID）和密码后连接。

使用局域网地址访问工具时，切换 WiFi 可能改变机器人的 IP 地址。连接后请使用新地址访问；也可以通过网线直连或机器人热点重新打开工具。

管理已保存网络与断开连接 ​

进入「WiFi 配置」→ 「已保存网络」：

  • 点击「连接」，使用该网络已保存的配置连接，无需再次输入密码。
  • 点击「删除」并确认，移除对应的已保存网络；以后连接该网络时需要重新配置。

需要断开当前 WiFi 时，进入 「状态」→「WiFi 连接」→「断开」，核对提示后确认。若网页正通过该 WiFi 访问，连接会随之中断，可改用网线或机器人热点访问。

查看机器人热点 ​

进入左侧「热点配置」页，可查看当前热点名称、IP 地址、运行状态与加密方式。密码默认隐藏。

  • 默认名称形如 H1_<设备ID>，实际名称以页面显示为准，开机自动开启。
  • 默认状态：热点开放，无密码。
  • 通过本工具连接带密码的 WiFi 后：热点密码自动同步为该 WiFi 的密码。
  • 通过本工具主动断开 WiFi 后：热点恢复为无密码；临时掉线不等于主动断开。
  • 此页用于查看热点信息，热点密码跟随 WiFi 自动同步，不需要也不支持手动修改。

若电脑当前通过机器人热点访问网页，机器人连接或断开 WiFi 后，可能需要使用更新后的密码重新连接热点，再打开 http://192.168.60.1:8080。

机器人标识与通信配置 ​

标识用途与修改方式
设备 ID由设备网卡地址生成，工具中不可修改
机器人 ID用户自定义的设备标识，例如 H1-LAB-01，在「机器人配置」页设置
序列号设备出厂标识，在「状态」页查看；修改机器人 ID 不会修改出厂序列号

设置机器人 ID 与导出配置 ​

  1. 进入左侧「机器人配置」页，在「基础配置」中填写机器人 ID。
  2. 点击 「保存」，收到保存成功提示后，查看下方「当前配置」确认结果。
  3. 需要放弃尚未保存的输入时，点击「重新加载」，恢复已保存内容。
  4. 需要备份时，点击「配置导出」中的 「导出 JSON」，将配置文件保存到电脑。

导出的 JSON 包含机器人 ID 等基础配置，不包含 WiFi 密码或 ROS 2 通信中间件配置。

查看 ROS 2 通信配置 ​

「机器人配置」页的「ROS 2 通讯中间件」卡片显示：

  • 本次启动使用：机器人此次启动时使用的通信实现。
  • 已保存配置：保存后供下次启动使用的配置；保存后尚未重启时，可能与上面的值不同。

H1 标准版和智能版当前统一使用原生 Zenoh（rmw_zenoh_cpp），日常使用保持默认设置即可。电脑端的配套设置见 ROS 2 通信配置。

高级操作：确需切换通信中间件时

切换可能影响机器人与外部设备的 ROS 2 通信。仅在已确认应用和电脑端的配套要求时操作：

  1. 在「通讯中间件」下拉框中选择配套的通信实现。
  2. 点击该卡片内的「保存」，核对确认提示后确认。
  3. 保存成功后，按页面提示重启机器人；页面保存操作不会自动重启。
  4. 重启后重新打开工具，确认「本次启动使用」与「已保存配置」一致，再进行通信检查。

「重新读取」用于读取当前配置。不要将“保存成功”当作当前运行环境已经切换。

整机 OTA 升级 ​

「OTA 升级」用于更新整机软件，使用厂商提供、与机器人匹配的 .img 升级包。

升级前确认

让机器人停止任务并保持静止，确认供电稳定、升级包与设备匹配。升级过程中不要断电或操作机器人，也不要同时启动其他类型的固件升级。

  1. 进入左侧「OTA 升级」页，确认顶部显示「空闲，可上传或升级」。
  2. 将 .img 文件拖入上传框，或点击上传框选择文件，等待上传完成。
  3. 在「已上传的 OTA 包」列表找到该文件，点击「升级」，核对文件名后确认。
  4. 查看顶部状态和「升级日志」，等待最终结果。上传完成只代表文件已传入机器人，还需要执行升级。
  5. 日志出现 ota升级成功 后，等待机器人自动重启，再重新连接网页，在「状态」→「机器人信息」中核对软件版本。

若出现 ota升级失败，保留页面错误信息并联系技术支持。整机、机械臂电机、自研夹爪和回充板固件包分别用于对应页面，不可混用，也不要通过改文件后缀来上传。

机械臂、夹爪与回充板固件升级 ​

这些页面用于更新对应硬件的固件。先按下表核对设备配置与升级包，再进入相应页面操作；共用上面的升级前确认事项。

页面升级文件适用对象
机械臂电机固件升级以小写 foc_ota 开头的 .bin 文件配套的机械臂电机
自研夹爪固件升级以小写 picker_ota 开头的 .bin 文件仅配备自研夹爪的机器人
回充板固件升级配套的 .bin 文件仅配备回充板的机器人

机械臂和夹爪的文件名前缀须符合表中要求，.bin 扩展名不区分大小写。请直接使用厂商提供的匹配文件；不确定硬件型号或升级包用途时，先联系技术支持确认。

机械臂电机固件升级 ​

  1. 点击左侧「机械臂电机固件升级」。
  2. 上传以 foc_ota 开头的 .bin 固件，等待文件出现在「已上传的机械臂电机固件」列表中。
  3. 点击对应文件的「升级」，核对文件名并确认。
  4. 查看「升级日志」，等待最终的「机械臂升级成功」或「机械臂升级失败」结果。

自研夹爪固件升级 ​

此功能仅适用于自研夹爪。使用其他型号夹爪时，不要在此页升级。

  1. 点击左侧「自研夹爪固件升级」。
  2. 上传以 picker_ota 开头的 .bin 固件，等待上传完成。
  3. 在「已上传的自研夹爪固件」列表中点击对应文件的「升级」，核对文件名并确认。
  4. 查看「升级日志」，等待最终的「夹爪升级成功」或「夹爪升级失败」结果。

当前页面会由升级程序自动查询夹爪 CAN ID，无需手动填写。日志中单独一侧夹爪的结果属于过程信息，应以整次升级的最终结果为准。

回充板固件升级 ​

仅配备回充板的机器人支持此功能。

  1. 点击左侧「回充板固件升级」。
  2. 上传与回充板匹配的 .bin 固件，等待上传完成。
  3. 在「已上传的回充板固件」列表中点击对应文件的「升级」，核对文件名并确认。
  4. 查看「升级日志」，等待最终的「回充板升级成功」或「回充板升级失败」结果。

各页的「删除」用于移除机器人中已上传的固件文件，不会卸载已安装的固件。升级期间等待当前操作结束，不要重复上传、删除或启动其他升级。

查看升级状态与结果 ​

升级在机器人侧独立执行，重新打开对应升级页面会自动检测并恢复显示状态。但无论如何都不要给机器人断电。

「开始监控」用于刷新升级日志，「停止监控」只停止当前页面的日志刷新，不会取消机器人正在执行的升级。判断是否结束，应查看最终成功 / 失败结果；不要通过关闭网页或停止监控来中断升级。

遇到问题 ​

页面打不开、热点密码变化、切换 WiFi 后失联或升级没有反馈时，请查看网络与升级常见问题。其中升级无反馈说明了启动等待与故障排查方法。
