机器介绍 ​

onero H1家庭服务机器人是一款先进的轮臂式人形机器人，专为重塑现代家庭服务体验而设计。onero H1基于 Ubuntu 和 ROS2 (Jazzy) 环境开发，SDK 提供了底盘、升降、头部、机械臂的底层运动控制接口，并集成了 SLAM、导航、目标识别、抓取等高级功能组件。作为智能生态中枢，H1深度集成环境感知技术，实现场景自适应的智能自动化服务，无缝执行精准烹饪、深度清洁及智能衣物护理等全方位家居任务。此外，H1还搭载多模态AI推理引擎，融合高精度视觉与多传感器数据，依托强大的端侧大模型处理能力构建高效边缘智能平台，确保敏捷响应与极致执行效率。

主要应用场景 ​

  • 家居场景： 整理衣物、洗衣服、地面清洁、刷马桶、整理冰箱物品等
  • 养老陪伴： 摔跤提醒、对话、递送物品等
  • 工厂场景： 产线自动化
  • 其他场景

环境配置 ​

  • 操作系统： Ubuntu
  • 中间件： ROS2 Jazzy
  • 开发语言： C++ / Python

设备信息获取 ​

  • 话题名： /device_info
  • 消息类型： std_msgs/msg/String
  • 发布频率： 1 Hz
  • 数据内容示例： {"type":"H-U11","device_id":"001A2B3C4D5E","address":"00:1A:2B:3C:4D:5E","sn":"HU1123070500000104"}

示例命令 ​

bash
ros2 topic echo /device_info
1

订阅示例（C++）：

cpp
auto sub = this->create_subscription<std_msgs::msg::String>(
    "/device_info", 10,
    [](const std_msgs::msg::String::SharedPtr msg) {
      // msg->data 就是上面的 JSON 字符串
    });
