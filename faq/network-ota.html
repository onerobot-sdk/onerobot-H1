网络配置与 OTA ​

下载《H1机器人网络配置和OTA功能使用文档》（PDF）

使用网络配置工具需 H1 固件版本 不低于 1.0.017.260509。具体界面随固件变化；升级前请按固件版本查询确认设备版本，并使用厂商提供的匹配升级包。

Q12. 怎么打开机器人的网络配置工具？ ​

机器人自带本地 Web 配网工具（浏览器直接打开即可配 WiFi、看热点、改配置、升级 OTA），端口 8080，三种接入方式任选：

接入方式地址场景
网线直连http://10.42.0.2:8080开发 / 调试
机器人热点http://192.168.60.1:8080手机 / 笔记本无线
同一局域网http://<机器人IP>:8080机器人已连入 WiFi（IP 见"状态"页 WiFi 卡片）

Q13. 机器人热点叫什么名字？有密码吗？ ​

  • 名称形如 H1_<设备ID>（例如 H1_9CB8B496E710），开机自动开启。
  • 未连过 WiFi 时：热点开放，无密码。
  • 连过 WiFi 后：热点密码自动同步为该 WiFi 的密码。
  • 断开 WiFi 后：热点恢复为无密码。
  • 热点密码跟随 WiFi 自动同步，不需要也不支持手动修改。

Q14. 怎么给机器人连接 WiFi？ ​

进入「WiFi 配置」页 → 列表按信号强度排序 → 点目标网络右侧「连接」→ 输入密码 → 「连接」。连接成功会提示 已成功连接到 <SSID>。隐藏或扫不到的网络用「手动连接」，输入 SSID + 密码即可。

Q15. 连过的 WiFi 怎么管理 / 断开？ ​

  • 管理：「WiFi 配置」页 →「已保存网络」标签，可直接复用（免再输密码）或删除。
  • 断开：「状态」页 → WiFi 连接卡片 →「断开」→ 确认。

Q16. "设备 ID"和"机器人 ID"有什么区别？ ​

  • 设备 ID：从 wlan0 MAC 地址派生（去掉冒号、转大写），不可改，如 9CB8B496E710。
  • 机器人 ID：在「机器人配置」页可自定义填写的标识（如 H1-XXXX-XXXX），保存后可导出备份。

Q17. 怎么做固件 OTA 升级？ ​

  1. 进入「OTA 升级」页，把 .img 升级包拖入虚线框（或点击选择文件）上传。
  2. 上传完成后，在「已上传的 OTA 包」列表点对应包的「升级」→ 确认。
  3. 顶部横幅变橙色「正在升级中」，升级日志每秒刷新，直到出现 ota升级成功（弹绿色提示，机器人自动重启）或 ota升级失败。

⚠️ 升级期间严禁断电、严禁给机器人断电；橙色横幅期间不要做其它操作。

Q18. 升级过程中不小心刷新了页面 / 换了设备登录，会中断升级吗？ ​

不会。升级在机器人侧独立执行，重新打开页面会自动检测并恢复显示进度。但无论如何都不要给机器人断电。

Q19. 点了升级后一直没反应怎么办？ ​

如果 20 秒内没有任何状态反馈，工具会自动提示"触发升级后无任何反馈"并解除锁定，可重试。若多次无效，请联系厂商技术支持。
