网络与升级常见问题 ​

本页回答网络连接、设备标识和固件升级中的常见问题。首次使用请查看网络配置与 OTA 使用说明，按图文步骤完成操作。

Q12. 怎么打开机器人的网络配置工具？ ​

先连接机器人，再在浏览器访问 8080 端口：网线直连使用 http://10.42.0.2:8080，连接机器人热点使用 http://192.168.60.1:8080，同一局域网使用 http://<机器人IP>:8080。详细说明见连接与访问。

网线已插好但页面打不开时，先核对电脑有线网卡设置：电脑使用 10.42.0.1、子网掩码 255.255.255.0，不要与机器人地址 10.42.0.2 重复。配置截图见网线直连设置，可直接查看 Ubuntu 或 Windows 步骤。

Q13. 机器人热点叫什么名字？有密码吗？ ​

默认名称形如 H1_<设备ID>，实际名称以「热点配置」页为准。热点默认开放、无密码；通过本工具连接带密码的 WiFi 后，热点密码同步为该 WiFi 的密码；通过本工具主动断开 WiFi 后，热点恢复为无密码。临时掉线不等于主动断开。

热点密码不支持在此页手动修改。热点信息的查看位置见热点配置说明。

Q14. 怎么给机器人连接 WiFi？ ​

在「WiFi 配置」中选择目标网络并连接；列表中找不到时，可刷新扫描或使用「手动连接」。连接成功后，在「状态」页核对网络名称和 IP 地址。完整步骤见连接 WiFi。

切换 WiFi 后原网页打不开，可能是机器人的局域网 IP 已改变。请使用新地址访问，或通过网线直连、机器人热点重新打开工具。

Q15. 连过的 WiFi 怎么管理 / 断开？ ​

「WiFi 配置」→「已保存网络」可连接或删除保存的网络；「状态」页的 WiFi 卡片可断开当前连接。删除保存的网络后，下次连接需要重新配置。

断开正在用于访问网页的 WiFi 后，网页连接也会中断，可改用网线或机器人热点访问。按钮位置见管理与断开 WiFi。

Q16. “设备 ID”和“机器人 ID”有什么区别？ ​

设备 ID 由设备网卡地址生成，在工具中不可修改；机器人 ID 是用户可自定义的设备标识，在「机器人配置」页设置。修改机器人 ID 不会修改设备的出厂序列号。

设置和备份方法见机器人 ID 与配置导出。导出的 JSON 包含基础配置，不包含 WiFi 密码或 ROS 2 通信中间件配置。

Q17. 怎么做固件 OTA 升级？ ​

整机软件在「OTA 升级」页使用厂商提供、与设备匹配的 .img 文件升级。上传完成只代表文件已传入机器人，还需要执行升级；升级期间保持供电，完成并重启后再次核对软件版本。

操作步骤见整机 OTA 升级。机械臂、夹爪和回充板使用各自的升级页面与配套固件，不与整机升级包混用。

Q18. 升级过程中刷新页面 / 换设备登录，会中断升级吗？ ​

不会。升级在机器人侧独立执行，重新打开对应页面会恢复显示状态。「停止监控」只停止当前页面的日志刷新，不会取消升级。

不要通过关闭网页、停止监控或断电来中断升级。 进度与结果的查看方法见升级状态说明。

Q19. 点了升级后一直没反应怎么办？ ​

如果触发升级后 20 秒内没有任何状态反馈，工具会提示「触发升级后无任何反馈」并解除页面锁定。这个时间是启动反馈等待时间，不是整次升级的完成时限。

先核对页面和升级包是否匹配，保留提示与日志，再联系技术支持。已经出现升级进度时，应等待最终结果，不要反复点击升级或断电重启。

在哪里查看机器人当前的固件版本？ ​

进入网络配置工具的「状态」→「机器人信息」→「软件版本」。机械臂电机、回充板的版本属于对应硬件固件，与整机软件版本分别管理。

页面位置见状态与版本查询，当前最新版本见固件版本公告。

ROS 2 通信配置保存后，为什么与当前使用的值不同？ ​

「本次启动使用」是此次启动时使用的通信实现；「已保存配置」供下次启动使用，保存后需要重启机器人才能生效，页面不会自动重启。

日常使用保持默认 Zenoh 设置即可。配置含义与高级操作见查看 ROS 2 通信配置。

机械臂、夹爪和回充板固件应该在哪个页面升级？ ​

各类固件用于对应硬件，操作前先确认设备配置和升级包是否匹配。入口如下：

硬件使用说明
机械臂电机机械臂电机固件升级
自研夹爪自研夹爪固件升级，仅适用于配备自研夹爪的机器人
回充板回充板固件升级，仅适用于配备回充板的机器人

升级时不要同时启动其他类型的升级任务。文件要求和完整操作见硬件固件升级说明。
