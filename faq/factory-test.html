出厂与跑机测试 ​

下载《H1 机器人跑机测试工具使用说明》（PDF）

该工具（factory_test）用于机器人出厂 / 交付前的功能验证：浏览器一键触发 SLAM 建图、定位、导航、机械臂老化与跑机压测，并实时反馈接口健康。需固件 不低于 1.0.026.260525。

Q20. 测试工具怎么访问？ ​

与网络配置工具接入方式相同，但端口为 8090，且免登录（产线内网无鉴权，Chrome / Edge 均可）：

接入方式地址
网线直连http://10.42.0.2:8090
机器人热点http://192.168.60.1:8090
同一局域网http://<机器人IP>:8090

Q21. 页面顶部的彩色圆点（chip）是什么意思？ ​

顶部状态条实时显示各算法/接口话题的健康度：● 绿 = 正常，● 黄 = 心跳超时（stale），● 红 = 从未收到 / 响应超时。出现红色 chip 说明对应节点没起来或挂了，请按提示排查，不要硬测。

Q22. 怎么建图（SLAM）？ ​

  1. 把机器人放到起点（一般为充电桩）。
  2. 「算法测试 → 建图」→ 点 开始建图（当前固定从充电桩起点，无需手填位姿）。
  3. 用遥控器遥控机器人遍历场地，"实时地图预览"会逐步显示扫描区域。
  4. 扫描完成点 完成建图，算法侧自动保存并加载地图。

⚠️ 建图期间，定位 / 导航 / 机械臂测试会被锁住，要做下一项先点「完成建图」。

Q23. 怎么做定位？ ​

需先建好图 → 把机器人放回充电桩（无充电桩原地定位也可）→「算法测试 → 定位」→ 启动定位 → 状态变为 locating_success 即可。定位成功后导航和机械臂测试不会被阻塞。

Q24. 怎么下发导航目标？ ​

两种方式二选一：

  • 预设点（推荐）：「导航到」一行点 P1 / P2 / P3 任一 chip 即下发；灰色 chip 表示未录入，需先录入。
  • 自定义位姿：填 x / y / yaw（弧度），按需勾选 is_accurate_pose，点 下发自定义点位。

Q25. 怎么录入 / 修改预设点 P1/P2/P3？ ​

把机器人开到目标位姿 → 确认定位为 locating_success → 在导航页点 记录当前点位为 P1 / P2 / P3。

⚠️ 录入的预设点只存内存，测试服务重启后会丢失并回到默认值。需要永久修改默认点位请联系厂商技术支持。

Q26. 怎么中止正在进行的导航？ ​

点导航页的 取消当前任务（红色按钮），机器人立即停止；该按钮始终可用。

Q27. 机械臂老化压测怎么做？安全要求是什么？ ​

填循环次数（默认 3，最少 1）→ 点 开始测试，机械臂重复一组动作；中止点 急停（任何时候都可点），结束后点 复位（运行中不能复位）。

⚠️ 安全须知：测试前机器人周围 2m×2m 无人、无障碍；建图/定位/导航必须全部停止；若页面急停无效，立即按本体物理急停或断电。

Q28. "跑机压测"是做什么的？ ​

用于长时间无人值守连续跑导航、头部活动和机械臂老化，重点暴露偶发的导航失败、接口异常和老化动作失败。采用"记错继续"策略——单点导航 60 秒未到达等失败会记入错误日志但不中断整轮。

⚠️ 开始前必须已建好图、定位成功、并在导航页录好点位；过程中机器人会自主移动、机械臂同步运动，现场务必无人靠近。

Q29. 系统诊断页能看什么？出问题怎么把信息给技术支持？ ​

「系统诊断 → 接口健康」列出所有话题的状态、所属组、更新时间和异常详情。遇到无法判断的问题，点 复制诊断信息 一键复制全文，连同操作步骤发给厂商技术支持，比口头描述高效得多。

Q30. 怎么预览各路摄像头画面？ ​

「系统诊断 → 摄像头」页可预览头部广角、左/右相机，以及安装了选配件时的头部 D435。实际画面数量和类型以设备配置为准，未安装的选配相机无图不代表故障。

打开页面时才建立预览订阅；图像传输会占用带宽和处理资源，关闭预览后释放。显示的帧率取决于相机与网络；相机话题和 QoS 见传感器。

Q31. 怎么下载机器人日志？ ​

「系统诊断 → 接口健康」页点 打包下载日志，会把机器人日志目录打成一个 zip 下载，文件名形如 h1_logs_<设备ID>_<时间>.zip。日志较大时进度会短暂停顿，属正常，请耐心等待。

Q32. 怎么录制 ROS Bag 交给研发分析？ ​

「系统诊断 → ROS Bag」页勾选话题（相机/点云等大流量话题单列在红色分组，按需单选）→ 开始录制 → 停止录制 → 在列表里下载（tar 包，解压后可 ros2 bag play 回放）。

⚠️ 磁盘剩余低于 2 GiB 会自动停止录制；bag 很占空间，用完请立即删除，避免写满磁盘影响机器人运行。同一时刻只允许一个录制，停止时请耐心等待写入完成，不要断电。

Q33. 执行器硬件测试页能做什么？ ​

「硬件测试 → 执行器」页用于出厂核对升降/头部的限位、堵转和报警，并支持校准与手动微调：

  • 限位开关：6 路（升降顶/底、头部俯仰到顶/到底、头部左/右到位），绿=未触发，黄=已到位/撞限位。
  • 电机告警：头部堵转（/head/stall）、升降报警（/lift/alarm，附报警码与中文描述）。
  • 处理堵转/报警：先停止操作、排除机械卡阻，再到「校准」区点 清除升降报警。

⚠️ 该页会直接驱动升降与头部执行器，操作前确认周围无人、上方及头部运动范围无遮挡。
