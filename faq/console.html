下载文件 ​

文件大小用途
下载 h1-web.tar（Docker 镜像）61.90 MiBlinux/amd64，导入后镜像名为 h1-web:latest
下载《H1任务编排控制台使用说明》（PDF）3.82 MiB完整操作说明

镜像适用于 linux/amd64，请确认电脑架构和机器人配套固件；其他架构需使用对应的软件包。

h1-web 是一个用 Docker 部署的网页控制台，浏览器即可操作机器人几乎全部功能：建图、定位、导航、遥控、拖拽式任务编排，以及人脸 / 语音 / 手势 / 动作 / 执行器 / 传感器 / 诊断 / TF。相比直接用 SDK，它更适合集成、交付、演示和日常操作。

Q34. 控制台怎么部署、启动？ ​

前提：电脑已安装 Docker，已从下载区保存 h1-web.tar，并能连接机器人的 HTTP Bridge（默认端口 8766）。在下载文件所在目录执行：

bash
docker load -i h1-web.tar
docker run -d --name h1-web -p 5173:80 h1-web:latest
1
2

浏览器打开 http://localhost:5173。Linux 是否需要在 Docker 命令前加 sudo 取决于本机配置；Docker Desktop 环境通常不需要。

Q35. 怎么连接到机器人？ ​

首次打开或点顶部「设置」→ 填入机器人 IP → 确认。后端默认使用 HTTP Bridge 端口 8766；网线直连示例为 10.42.0.2:8766。前端页面的 5173 端口与机器人后端的 8766 用途不同，不要混填。

顶部状态栏绿色表示已连接，红色表示连接失败。若部署时修改了后端端口，以配套配置为准。

Q36. 收到新版镜像怎么更新？ ​

bash
docker stop h1-web && docker rm h1-web
docker rmi h1-web:latest        # 可选，释放空间
docker load -i h1-web.tar
docker run -d --name h1-web -p 5173:80 h1-web:latest
1
2
3
4

更新后刷新浏览器即可（Linux 是否需要 sudo 取决于本机 Docker 权限）。

Q37. 操作机器人有没有固定顺序？ ​

有：先建图 → 再定位 → 最后导航，不可跳步。导航、沿路径导航、回充等所有导航类功能，必须在定位成功（locating_success）之后才能使用，未定位时操作会失败。

Q38. 怎么建图？ ​

前提：当前无已有地图（有旧地图需先重置 SLAM → 删除地图）。把机器人放到起点 →「建图控制」→ 开始建图 → 用方向键遥控走遍需覆盖区域 → 结束建图（自动保存）。建图中可「中途保存」；建议慢速行走并尽量走闭合回路以提高精度。

Q39. 怎么定位？ ​

前提：已有地图。「定位控制」→ 选起始位置（上次位姿 / 指定位姿 / 充电桩）→ 开始定位 → 等状态变 locating_success。失败就把机器人放回充电桩重试。定位 / 导航过程支持暂停 / 恢复。

Q40. 怎么导航到目标点？ ​

定位成功后，在地图上单击选点（或手动填 X / Y / Heading，弧度 -3.14~3.14）→ 发送目标。目标点必须在地图白色自由区内；同一时间只能执行一个导航任务，导航中可点「停止导航」中止。

Q41. "沿路径导航"和普通导航有什么区别？ ​

普通导航是机器人自主规划路线到单个目标；沿路径导航在「任务编排」里拖入路径导航节点，双击后在地图上依次点选多个路径点，机器人严格按顺序行走（点间走直线，需绕行就多加中间点），适合固定巡检路线。

Q42. 怎么回充？ ​

回充 = 两步：先「回充(到桩前)」导航到充电桩预备位，再「上桩对接」执行上桩。右侧面板有手动「回充」按钮；任务编排里需把两个节点串联（先到桩前成功 → 再上桩）。

Q43. 怎么删除地图 / 重新建图？ ​

必须先点「重置 SLAM」（使其回到 IDLE）→ 再点「删除地图」。删除不可撤销，之后需重新建图 + 定位才能导航。

Q44. 任务编排（自动化流水线）怎么用？ ​

切到「任务编排」→ 从左侧拖拽节点到画布 → 从节点输出端口拖线到下一节点 → 单击节点编辑参数 → 执行流程。连线颜色代表触发条件：🟢 绿 = 成功、🔴 红 = 失败、🟡 黄 = 超时（可用红色端口做失败处理，例如导航失败 → 回充）。新增循环执行节点：设 loop_count 次数，把流程末端连回该节点即可按成功 / 失败 / 超时重复执行。

Q45. 遥控快捷按钮在哪？ ​

地图视图右侧面板底部有方向键（▲ 前进 / ▼ 后退 / ◀ 左转 / ▶ 右转 / ■ 停止，按住持续移动、松开即停）
