SLAM ​

对外提供地图构建、定位和坐标变换能力。

话题总览 ​

发布话题 ​

话题消息类型频率说明
slam/posegeometry_msgs/msg/PoseStamped50 Hz当前位姿（定位/建图初始化完成后才发布）
/mapnav_msgs/msg/OccupancyGrid1 Hz栅格地图（仅建图/定位正常工作时发布）
refined_mapnav_msgs/msg/OccupancyGrid0.25 Hz精细化地图（定位工作时发布）

建图接口 ​

触发建图 ​

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start_mapping\", \"detail\": {\"from_where\": \"charge\"}}'"
1
字段类型必填说明
detail.from_wherestring否起始位置，默认 "charge"。可选值见 from_where 枚举

行为：强制 mode=0（建图），清除旧地图数据，进入主方向识别阶段（PRE_MAPPING），识别成功后开始建图。

建图状态查询 ​

  • 话题： slam/mapping_status
  • 同步获取： ros2 topic pub --once /sync_slam_status std_msgs/msg/Empty "{}"
json
{"state": "idle"}                                         // 未在建图
{"state": "preparing"}                                    // 主方向识别阶段
{"state": "mapping"}                                      // 建图中
{"state": "mapping_completed"}                            // 建图完成
{"state": "mapping_failed", "reason": "location_lost"}    // 失败：定位丢失
{"state": "mapping_failed", "reason": "save_map_failed"}  // 失败：保存地图失败
{"state": "paused"}                                       // 暂停中

建图预览 ​

  • 话题： /map (nav_msgs/msg/OccupancyGrid)
  • 发布频率： 1 Hz
  • 条件： 仅在建图正常运行时发布（PRE_MAPPING、暂停、故障、重定位阶段不发布 /map）

结束建图并保存地图 ​

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"stop_mapping\"}'"
1

成功后 slam/mapping_status 依次发布 mapping_completed → idle。地图保存到 /data/slam/map.pbstream。

手动保存地图 ​

建图过程中可随时保存当前地图（不结束建图）。

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"save_map\"}'"
1

保存完成后 has_map 标记为 true，后续暂停恢复时将走定位路径。

删除地图 ​

删除已保存的地图文件并清空内存缓存。

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"delete_map\"}'"
1
  • 前置条件：SLAM 处于 IDLE 状态
  • 行为：删除 /data/map_server/map/ 下所有地图文件，清空栅格地图内存缓存
  • 删除后 GetMap 服务返回空地图（width=0, height=0）
  • 删除后执行 start_locating 将因无地图报故障

地图包导入导出 ​

地图包为 zip 格式，包含栅格地图、精细化地图、标记点、标签等完整数据。

导出地图包 ​

将当前地图打包为 zip 文件，返回文件路径。

bash
ros2 service call /map_server/package std_srvs/srv/Trigger
1

响应示例：

yaml
success: true
message: "/tmp/map_51e02458-1419-4c8f-9d14-5d418d468a04.zip"
1
2
  • 前置条件：map_server 节点运行中，且已有地图数据
  • 行为：将 /data/map_server/map/ 目录压缩为 zip 到 /tmp/
  • 输出文件可通过 scp/http 等方式传输到其他设备

导入地图包 ​

从 zip 文件导入地图，替换当前地图。

bash
ros2 topic pub --once /map_server/setmap std_msgs/msg/String "data: '/path/to/map.zip'"
1
  • 消息内容为 zip 文件在设备上的绝对路径
  • 行为：清空当前地图 → 解压 zip → 写入 /data/map_server/map/ → 刷盘
  • 导入完成后发布 MAP_PACKAGE_CHANGED 事件
  • 导入后可直接执行 start_locating 使用新地图

地图包结构 ​

map.zip
├── mapinfo.json         # 元信息（uuid, name, version, robot_model, layer）
├── map.pgm              # 栅格地图图片
├── map.json             # 地图元数据（resolution, origin）
├── map.raw              # SLAM 内部概率地图（pbstream 序列化）
├── hotmap.bin           # 热力图
├── start_pose.json      # 起始位姿
└── refined/             # 精细化地图 layer
    ├── map.pgm
    └── map.json

定位接口 ​

开始定位 ​

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start_locating\", \"detail\": {\"from_where\": \"charge\"}}'"
1
字段类型必填说明
detail.from_wherestring否起始位置，默认 "charge"
detail.modeint否定位模式，默认 1。传入 0 会被强制修正为 1

行为：加载已有地图（/data/slam/map.pbstream），从指定位置开始重定位。若无已保存地图则直接报故障。

定位状态查询 ​

  • 话题： slam/locating_status
  • 同步获取： ros2 topic pub --once /sync_locate_status std_msgs/msg/Empty "{}"
json
{"state": "idle"}                                           // 未在定位
{"state": "locating"}                                       // 定位中（重定位进行中）
{"state": "locating_success"}                               // 定位成功，正常追踪
{"state": "locating_failed", "reason": "no_map"}            // 失败：没有地图
{"state": "locating_failed", "reason": "relocating_fail"}   // 失败：重定位失败
{"state": "locating_failed", "reason": "location_lost"}     // 失败：跟踪丢失
{"state": "paused"}                                         // 暂停中

通用 start 指令 ​

通过 mode 字段决定建图还是定位。

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start\", \"detail\": {\"from_where\": \"charge\", \"mode\": 1}}'"
1
mode行为
0建图模式：清除旧图，进入主方向识别 → 建图
>=1定位模式：加载已有地图 → 重定位。若无地图则报故障

start 指令额外支持 "given_pose" 起始位置：

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start\", \"detail\": {\"from_where\": \"given_pose\", \"mode\": 1, \"x\": 1.0, \"y\": 2.0, \"yaw\": 0.785}}'"
1

通用控制指令 ​

暂停 ​

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"pause\"}'"
1

恢复 ​

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"resume\", \"detail\": {\"from_where\": \"charge\", \"mode\": 0}}'"
1
字段类型必填说明
detail.from_wherestring否恢复时的初始位置
detail.modeint否0=建图, >=1=定位

恢复行为：

  • 短暂暂停（< 1 秒且定位评分 > 0.5）：直接恢复，无需重定位
  • 其他情况：从指定位置重新执行重定位，重定位成功后根据 has_map 决定进入建图或定位

from_where 额外支持：

  • "lastpose" — 从上次暂停时的位姿恢复
  • "given_pose" — 指定位姿恢复（需附带 x、y、yaw）
bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"resume\", \"detail\": {\"from_where\": \"given_pose\", \"mode\": 1, \"x\": 1.5, \"y\": 2.0, \"yaw\": 0.785}}'"
1

重置 ​

停止并重置 SLAM 系统到空闲状态。

bash
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"reset\"}'"
1

from_where 枚举值 ​

值说明
"charge"充电桩（默认）
"water"水基站
"humidifier"加湿器
"platform"平台（定位模式下会触发旋转重定位）
"combined"组合基站
"given_pose"外部指定位姿（需附带 x, y, yaw）

仅 resume 额外支持：

值说明
"lastpose"从上次暂停位姿恢复

/slam/status 总体状态 ​

  • 话题： slam/status
  • 同步获取： ros2 topic pub --once sync_status std_msgs/msg/Empty "{}"
状态字符串含义
"idle"空闲
"preparing"准备中（重定位/主方向识别未完成）
"working"正常工作（建图或定位追踪中）
"relocating"静态重定位中
"explore_relocating"探索重定位中
"pause"暂停
"fault"故障
"starting"启动中（过渡状态）
"resuming"恢复中（过渡状态）
"pausing"暂停中（过渡状态）
"resetting"重置中（过渡状态）

故障时附带原因：

json
{"state": "fault", "detail": {"reason": "initialize slam fail"}}
{"state": "fault", "detail": {"reason": "static relocating fail"}}
{"state": "fault", "detail": {"reason": "explore relocating fail"}}
{"state": "fault", "detail": {"reason": "location lost"}}

重定位与恢复逻辑 ​

重定位成功后的行为 ​

重定位成功后，系统根据 has_map 标记决定进入的模式：

条件目标状态场景
has_map = false建图（Mapping）建图模式暂停后恢复
has_map = true定位（Locating）定位模式正常启动/恢复

定位丢失恢复 ​

定位工作中若发生跟踪丢失：

  • 系统自动进入恢复重定位（扩大搜索窗口）
  • 5 分钟内恢复成功 → 继续定位/建图
  • 5 分钟超时 → 报故障

探索重定位 ​

当静态重定位失败时，系统当前已禁用探索重定位（因机械安全限制），直接报故障。状态机路由仍保留但不再触发。

指令前置条件 ​

指令前置条件不满足时行为
start / start_mapping / start_locating当前为 IDLE忽略指令，重新发布当前状态
resume当前为 PAUSE忽略
reset / stop_mapping当前不为 IDLE忽略
pause当前不为 IDLE 且不为 PAUSE忽略
save_map当前不为 IDLE忽略
delete_map当前为 IDLE忽略
  • FAULT 状态下仅接受 reset
  • 过渡状态（STARTING / RESUMING / PAUSING / RESETTING）不接受任何新指令

ROS2 服务接口 ​

服务名类型说明
map_server/mapnav_msgs/srv/GetMap获取当前栅格地图
map_server/refined_mapnav_msgs/srv/GetMap获取精细化栅格地图
map_server/packagestd_srvs/srv/Trigger导出地图包（返回 zip 文件路径）

JSON 指令汇总 ​

指令说明
{"cmd": "start_mapping", "detail": {"from_where": "charge"}}开始建图
{"cmd": "stop_mapping"}结束建图并保存地图
{"cmd": "save_map"}手动保存当前地图（不结束建图）
{"cmd": "delete_map"}删除地图文件并清空缓存（仅 IDLE 状态）
{"cmd": "start_locating", "detail": {"from_where": "charge"}}开始定位（无地图则报故障）
{"cmd": "start", "detail": {"from_where": "charge", "mode": 1}}通用启动（mode=0 建图，mode>=1 定位）
{"cmd": "pause"}暂停当前操作
{"cmd": "resume", "detail": {"from_where": "charge", "mode": 0}}从暂停恢复
{"cmd": "reset"}重置到空闲状态

示例命令 ​

bash
# 开始建图
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start_mapping\", \"detail\": {\"from_where\": \"charge\"}}'"

# 结束建图
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"stop_mapping\"}'"

# 手动保存地图（不结束建图）
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"save_map\"}'"

# 删除地图
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"delete_map\"}'"

# 开始定位
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start_locating\", \"detail\": {\"from_where\": \"charge\"}}'"

# 通用启动（建图模式）
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start\", \"detail\": {\"from_where\": \"charge\", \"mode\": 0}}'"

# 通用启动（定位模式）
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start\", \"detail\": {\"from_where\": \"charge\", \"mode\": 1}}'"

# 通用启动（指定位姿定位）
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"start\", \"detail\": {\"from_where\": \"given_pose\", \"mode\": 1, \"x\": 1.0, \"y\": 2.0, \"yaw\": 0.0}}'"

# 暂停
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"pause\"}'"

# 恢复（从充电桩位置）
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"resume\", \"detail\": {\"from_where\": \"charge\", \"mode\": 1}}'"

# 恢复（从上次位置）
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"resume\", \"detail\": {\"from_where\": \"lastpose\", \"mode\": 1}}'"

# 恢复（指定位姿）
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"resume\", \"detail\": {\"from_where\": \"given_pose\", \"mode\": 1, \"x\": 1.5, \"y\": 2.0, \"yaw\": 0.785}}'"

# 重置
ros2 topic pub --once /slam/cmd std_msgs/String "data: '{\"cmd\": \"reset\"}'"

# 查看当前位姿
ros2 topic echo slam/pose

# 同步获取建图状态
ros2 topic pub --once /sync_slam_status std_msgs/msg/Empty "{}"

# 同步获取定位状态
ros2 topic pub --once /sync_locate_status std_msgs/msg/Empty "{}"

# 同步获取总体状态
ros2 topic pub --once sync_status std_msgs/msg/Empty "{}"

# 监听建图状态
ros2 topic echo slam/mapping_status

# 监听定位状态
ros2 topic echo slam/locating_status

# 监听总体状态
ros2 topic echo slam/status

# 获取栅格地图（ROS2 服务）
ros2 service call /map_server/map nav_msgs/srv/GetMap "{}"

# 获取精细化地图（ROS2 服务）
ros2 service call /map_server/refined_map nav_msgs/srv/GetMap "{}"

# 导出地图包
ros2 service call /map_server/package std_srvs/srv/Trigger

# 导入地图包
ros2 topic pub --once /map_server/setmap std_msgs/msg/String "data: '/tmp/map.zip'"
